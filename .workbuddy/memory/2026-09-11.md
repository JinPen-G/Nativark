## 分析 BoardUI 明暗主题切换实现（外部参考）
用户要求看 https://www.boardui.com/templates/dashboard 的主题切换效果。该站为 Next.js App Router 站点，本机沙箱无法启动浏览器渲染，故改为**从构建产物反推实现**（下载 3 个 CSS chunk + 40 个 JS chunk，定位到主题逻辑 chunk `074vo1xbpnia1.js`）。

### 结论（可直接复用）
- **主题落地方式**：`<html>` 上的 `.dark` 类。localStorage 键 `boardui:theme`，值 `"light"` / `"dark"`，**默认 light，不读 `prefers-color-scheme`**。
- **防闪白**：`beforeInteractive` 内联脚本在任何渲染前读 localStorage 并 `classList.toggle("dark", ...)`；服务端渲染快照固定为 `light`，避免 hydration 不一致。
- **切换动画**：`document.startViewTransition()` + **自定义 mask 圆形揭示**，默认 `820ms`，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`。
  - 遮罩用内联 SVG data URI：`viewBox 0 0 100 100` 的白色圆 `r=42` + `feGaussianBlur stdDeviation="2"` → **软边圆**。
  - 圆心取点击元素中心（`getBoundingClientRect`），半径 `R = hypot(max(x, W-x), max(y, H-y))`（到最远角），遮罩尺寸动到 `2.5R`。
  - 关键帧：`mask-size 0→2.5R`，`mask-position (x,y) → (x-1.25R, y-1.25R)`，使圆心全程锁定在点击点。
  - 过渡期间给 `<html>` 加 `.theme-transitioning`，其规则是 `transition: none !important`，避免逐元素颜色过渡与圆形揭示叠加。
  - `prefers-reduced-motion: reduce` 或无 `startViewTransition` 支持 → 直接瞬时切换。
  - 用 `flushSync` 在 transition 回调内同步应用主题；并发保护布尔量防重入。
- **CSS 侧**：`::view-transition-old(root){animation:none;z-index:1}`、`::view-transition-new(root){animation:none;z-index:2}` —— 关掉默认交叉淡入，改由 mask 动画负责揭示。
- **附带第二套可变量**：accent 色也持久化（`boardui:accent`，存 JSON ramp），启动脚本把 `--color-accent-*` 写到 `<html>` 内联样式并加 `data-accent`。
- **设计令牌双层结构**：语义 token（`--color-background-primary-default`、`--color-text-primary`…）在 `:root` 定义、`.dark` 覆盖；底层原语为 neutral 50→950（#fafafa→#0a0a0a，含自定义档 `neutral-925: #121212`），accent = blue（500 `#3080ff` / 600 `#155dfc`）。
- 值得注意：`.dark` **不覆盖** `--color-text-secondary`（两级主题都保持 `neutral-500 #737373`）。

### 产出
- 用 show_widget 做了一版**忠实复现**（含同样令牌、同样分段切换控件、同样 820ms 软边圆揭示），供用户在无法访问原站渲染时对照；复现改用 Web Animations API 在容器内做 mask 动画，未调用 `startViewTransition`（避免污染宿主文档）。

### 对本站的潜在用途
若 `apps/admin` 或官网要做明暗主题，可直接沿用此方案；注意本项目前端是 React 19 + Vite（非 Next.js），`beforeInteractive` 脚本需改为 `index.html` 中 `<head>` 内的普通同步脚本。
