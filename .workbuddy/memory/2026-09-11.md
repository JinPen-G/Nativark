## 分析 BoardUI 明暗主题切换实现（外部参考）
用户要求看 https://www.boardui.com/templates/dashboard 的主题切换效果。该站为 Next.js App Router 站点，本机沙箱无法启动浏览器渲染，故改为**从构建产物反推实现**（下载 3 个 CSS chunk + 40 个 JS chunk，定位到主题逻辑 chunk `074vo1xbpnia1.js`）。

### 结论（可直接复用）
- **主题落地方式**：`<html>` 上的 `.dark` 类。localStorage 键 `boardui:theme`，值 `"light"` / `"dark"`，**默认 light，不读 `prefers-color-scheme`**。
- **防闪白**：`beforeInteractive` 内联脚本在任何渲染前读 localStorage 并 `classList.toggle("dark", ...)`；服务端渲染快照固定为 `light`，避免 hydration 不一致。
- **切换动画**：`document.startViewTransition()` + **自定义 mask 圆形揭示**，默认 `820ms`，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`。
  - 遮罩用内联 SVG data URI：`viewBox 0 0 100 100` 的白色圆 `r=42` + `feGaussianBlur stdDeviation="2"` → **软边圆**。
  - 圆心取点击元素中心（`getBoundingClientRect`），半径 `R = hypot(max(x, W-x), max(y, H-y))`（到最远角），遮罩尺寸动到 `2.5R`。
  - 关键帧：`mask-size 0→2.5R`，`mask-position (x,y) → (x-1.25R, y-1.25R)`，使圆心全程锁定在点击点。
  - 过渡期间给 `<html>` 加 `.theme-transitioning`，其规则是 `transition: none !important`，避免逐元素颜色过渡与圆形揭示叠加。
  - `prefers-reduced-motion: reduce` 或无 `startViewTransition` 支持 → 直接瞬时切换。
  - 用 `flushSync` 在 transition 回调内同步应用主题；并发保护布尔量防重入。
- **CSS 侧**：`::view-transition-old(root){animation:none;z-index:1}`、`::view-transition-new(root){animation:none;z-index:2}` —— 关掉默认交叉淡入，改由 mask 动画负责揭示。
- **附带第二套可变量**：accent 色也持久化（`boardui:accent`，存 JSON ramp），启动脚本把 `--color-accent-*` 写到 `<html>` 内联样式并加 `data-accent`。
- **设计令牌双层结构**：语义 token（`--color-background-primary-default`、`--color-text-primary`…）在 `:root` 定义、`.dark` 覆盖；底层原语为 neutral 50→950（#fafafa→#0a0a0a，含自定义档 `neutral-925: #121212`），accent = blue（500 `#3080ff` / 600 `#155dfc`）。
- 值得注意：`.dark` **不覆盖** `--color-text-secondary`（两级主题都保持 `neutral-500 #737373`）。

### 产出
- 用 show_widget 做了一版**忠实复现**（含同样令牌、同样分段切换控件、同样 820ms 软边圆揭示），供用户在无法访问原站渲染时对照；复现改用 Web Animations API 在容器内做 mask 动画，未调用 `startViewTransition`（避免污染宿主文档）。

### 对本站的潜在用途
若 `apps/admin` 或官网要做明暗主题，可直接沿用此方案；注意本项目前端是 React 19 + Vite（非 Next.js），`beforeInteractive` 脚本需改为 `index.html` 中 `<head>` 内的普通同步脚本。

## 查证：BoardUI 的按钮圆角（含 antd 侧的可改路径）
用户要求查 BoardUI 按钮用的圆角。**结论来自其 Button 组件源码**（`bchunks/0bjcqq0~mp92p.js`），圆角**按尺寸分档，不按变体**：

```js
size: {
  medium: "h-9 rounded-2lg p-2",        // 36px 高 → 10px
  small:  "h-8 rounded-lg px-2 py-1.5", // 32px 高 → 8px
  xs:     "h-6 rounded-sm px-2"         // 24px 高 → 4px
}
```

圆角刻度：`xs 2 / sm 4 / md 6 / lg 8 / 2lg 10（自定义档）/ xl 12 / 2xl 16 / 3xl 24 / full`。
主按钮 `Create ticket` = `h-9 rounded-2lg`（36px / 10px）。侧栏菜单项也是 `rounded-2lg`（10px）。
注意 `rounded-[3px]`（出现 259 次）是贡献热力图格子 `contribution-cell`，**不是按钮**，别被计数误导。

### 管理端现状（antd 实算）
`Button.controlHeight: 36`（theme.tsx 覆盖）；圆角走全局 `borderRadius: 6`（`borderRadiusSM 4`、`borderRadiusLG 8`）。
→ 同为 36px：BoardUI 10px vs 管理端 6px；同为 24px：BoardUI 4px vs 管理端 4px（**已一致**）。

### 关键约束（决定怎么改）—— 已实测修正
**antd v6 的 Button 没有 `borderRadius` 组件令牌** —— 逐字段核对过 `node_modules/antd/es/button/style/token.d.ts` 的 43 个字段，没有任何 radius。Button 消费的是全局圆角族，**按尺寸分三档**（来自 `antd/es/button/style/index.js`）：

| 按钮尺寸 | 取的令牌 | 本仓当前值 |
| --- | --- | --- |
| 默认（controlHeight 36） | `borderRadius` | 6px |
| `size="small"`（24） | `borderRadiusSM` | 4px |
| `size="large"`（40） | `borderRadiusLG` | 8px |
| `shape="circle"` | 固定 50% | — |
| `shape="round"` | `controlHeight`（药丸） | — |

`borderRadius` 是 **SeedToken**（`theme/interface/seeds.d.ts`），`borderRadiusXS/SM/LG/Outer` 是 **MapToken**（`maps/style.d.ts`），由 `theme/themes/shared/genRadius.js` **阶跃派生、不是线性**（base∈[6,16) → LG=base+2；SM 分档 4/5/6/7/8）。

**实测（`theme.getDesignToken`）：**
- `borderRadius: 6`（现状）→ base 6 / SM 4 / LG 8
- 只改 `borderRadius: 10` → base 10 / **SM 6 / LG 12**（三档一起动）
- `borderRadius: 10` + 显式 `borderRadiusSM: 4, borderRadiusLG: 8` → base 10 / SM 4 / LG 8 ✅ **可只改一档**

因为 `ThemeConfig.token` 的类型是 `Partial<AliasToken>`（含 MapToken），**可以同时传 seed 与派生档**并把派生档钉住。所以改按钮圆角实际有三条路：
- (a) 只调 `borderRadius`：三档联动，且会连带 Input / Select / Card / Table（它们也吃同一族）。
- (b) **在 `token` 里显式钉住 `borderRadiusSM` / `borderRadiusLG`**：只改默认档，其余不动。**推荐**。
- (c) styles.css 里按 `.ant-btn` 写死：只影响按钮，但绕过主题令牌，不推荐长期用。

本仓唯一影响按钮圆角的 CSS 是 `.ant-btn-circle, .ant-btn.ant-btn-icon-only { border-radius: 50% }`；`.ant-segmented` / `.ant-tabs` / `.appearance-toggle` 那些 999px 是写死的，不受主题圆角影响。
按钮尺寸实际用量：`size="small"` 十余处、`size="large"` 3 处、`shape="circle"` 2 处 —— 三档都在用。

本次**只查证、未改动代码**，等用户决定是否应用。
