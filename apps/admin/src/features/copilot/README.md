# 业务 Copilot：本地交互预览

与 AI 工作中心的能力会话分离。入口在后台右上角铃铛前，侧栏可关闭、重开；本轮只演示上下文、消息、页面导航和方案核对，不连接模型或执行业务写入。

## 交互

- 右击列表行、卡片或已接入的详情概览，菜单针对**整个业务对象**。金额、状态、客户等位置不会生成单独字段上下文。
- 「询问 Copilot」加入记录并展开侧栏、聚焦输入；「添加到 Copilot」只累积记录。两者均不自动发送。
- 右击已选行针对该表已选记录；右击未选行仅针对当前行。原多选浮窗追加同名入口，原业务操作不变。
- 按来源页面和记录定位去重；重复添加更新快照。标签可逐个移除，发送后保留本轮来源及采集时间。
- 现阶段多选只接收当前已渲染、可读取的选中记录；不把离页、未加载记录当成已获取上下文。
- 中文输入法组合期间回车不发送；Enter 发送，Shift+Enter 换行。支持停止、重试、新对话和本地方案确认。
- 文字选区、输入框、链接及普通操作按钮保留原有右键行为。客户预览仍使用原左键行为，右键归属所在业务记录。

## 页面定位、详情与配置

- `destinations.ts` 登记可定位的页面、页签与分区；自然语言演示只匹配这些固定目标。明确说“帮我打开/跳转到”时直接导航，其余提供可点击入口。服务端接入后只能返回登记目标 ID，不能传任意 URL、CSS 选择器或脚本。
- 目前定位覆盖业务规则/逾期/取消、营业日历、计价与履约方式、主题色、圆角、动效和音效；入口按原路由及页签权限过滤。加载后滚动、高亮并聚焦；目标不存在时反馈不可用，不伪造已定位。减少动态时取消平滑滚动与呼吸效果。
- 订单概览及共享资料详情提供“分析当前资料”，按当前状态、计划时间、资金摘要整理已显示的对象资料。本地模板不推导欠款、风险等级或处理资格，不读取隐藏页签或新业务资料。
- `CopilotSection` 以完整配置分区登记必要字段。业务规则只解释已生效版本；不自动打开草稿或发布。圆角设置支持当前值/建议值、差异核对、确认后填入原表单的未保存草稿；仍需原保存按钮提交。
- 圆角演示可识别单个数字，例如“按钮圆角调整到16”，只接受原控件允许的范围；不明确的建议需用户从原 Select 中选择，不伪称模型推断。确认时重新核对当前页面、挂载分区、可编辑状态、旧值及允许选项，任一变化都拒绝填入。
- 未登记的配置、业务规则、资金和权限设置不会根据文字自动修改。新增填入能力须由所属表单提供受控回调，不能扫描表单后任意写值或自动提交。

## 共享接入

`Table` / `DataTable` / `RecordCard` 提供对象标记和安全显示字段，`RecordDetailLayout` 与订单概览提供详情对象，工作台及经营报表提供整项指标。页面不得各自复制右键菜单。

`data-copilot-record` 为本地定位，`data-copilot-id` 为可选业务引用；字段标记只用于构成对象摘要，**不是字段级操作入口**。新增区域应明确标记对象边界、名称和必要显示字段；不扫描任意网页文本，不读取整份 API 对象。

## 接入后端时

- 替换 `CopilotProvider.send` 的本地定时回复；保留 `CopilotRecord` 对象来源、引用、显示摘要、采集时间及逐轮快照。
- 本地 DOM 定位不是可信业务 ID；后端按对象类型重新解析引用、校验租户/空间/当前用户权限并读取新数据。显示摘要不能作为写入依据。
- 不采集隐藏字段、密钥、密码、完整联系方式或证件号；禁止把 DOM、模型输出 HTML 或脚本直接执行。
- 后端返回真实分析、可核对方案、执行回执和未知结果状态；本地“确认”不能直接改接到业务写接口。真实确认必须绑定方案版本、对象范围与幂等命令。
- 当前未提供模型、工具调用、附件上传、持久历史、跨设备同步及业务撤销。演示状态不能用于证明业务已完成。

## 生命周期与适配

上下文及会话只存在当前内存；租户、空间、用户、会话代次或权限变化时清空。可导航入口沿用原路由授权。进入 AI 工作中心时暂停显示业务侧栏，不混入能力会话。

按负责人指定的 UIArc Product listing Screen，桌面中间内容区与 Copilot 为各有边框、圆角和底色的独立同级面板，上下对齐；租户外部上/下/右留8px，两个面板间隔8px。聊天宽度按原站采用340px，开关沿原曲线，关闭后中间内容归还宽度。头部位于中间面板，聊天会话与输入草稿保留同一挂载；不足640px时沿原74%高度底部面板、焦点与关闭规则。主题色、圆角、动效偏好与点击音效复用平台现有体系。来源及导入哈希见 [SOURCE.md](archive/SOURCE.md)。

原示例 CSS 的重置类限定在聊天面板内部，不包裹中间内容与头部；原 [构建适配](../../../config/copilotArchiveStyles.ts) 对 `data-admin-content` 业务子树的保护继续保留，避免业务按钮背景、描边、禁用或焦点被聊天样式覆盖。归档源码与动效不改，独立面板边界、间隔和窄屏定位仅由宿主适配。
