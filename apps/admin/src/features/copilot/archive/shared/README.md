# Reference service marks

`reference-marks.json` contains vector marks captured from the publicly rendered AI chat and Agent approvals previews at https://uiarc.dev/components/blocks/ai-chat and https://uiarc.dev/components/blocks/agent-approvals on 2026-10-26 / 2026-10-27. This is visible SVG artwork, not recovered component TypeScript or a registry source response. `BrandMark.tsx` renders only the bundled known mark registry, never SVG supplied through user messages or component props.

The Slack vector was captured from the publicly rendered Tool call preview at https://uiarc.dev/components/tool-call on 2026-10-27. The original public SVG paths and fill colors are retained.

The npm and TypeScript vectors were captured from the publicly rendered Agent run preview at https://uiarc.dev/components/blocks/agent-run on 2026-10-27, retaining the public SVG paths and colors.

Marks identify the corresponding provider/service in the reference examples. They do not brand the local gallery or imply a connection, endorsement or an available live model. Default demonstrations never call these services. Preserve provenance and dependency license notices when transferring components, and use your own supported providers in a business integration.
