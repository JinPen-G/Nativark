# AI运营官前端演示

入口：租户侧栏的「AI运营官 / 管理后台」，路由 `/ai-operator`。管理后台原菜单与业务页保持独立，切回时返回上次管理页面。

## 组件来源

- [UIArc ChatThread](https://uiarc.dev/components/chat-thread)：原消息流、附件选择与输入框。
- [UIArc ResizablePanels](https://uiarc.dev/components/resizable-panels)：原拖动、折叠、恢复、键盘与分栏动效。
- UIArc Accordion、Card：演示步骤、插件卡片；表单与确认复用后台统一适配层。
- Animate UI Base UI Sidebar 与原 Hugeicons：保留现有侧栏主题、圆角、尺寸及交互。

未使用 UIArc Pro AI Chat 模板源码。未改动上述 vendor 文件。所有原组件通过项目现有构建适配读取同一动态偏好。

## 状态与边界

- `OperatorProvider` 位于已认证的租户/空间 AppShell 内；切换空间或账号后跟随原 shell 卸载清空。刷新后不保留聊天、任务与插件开关，不写业务缓存或localStorage。
- 页面沿既有路由授权展示能力，插件开关仅控制本次演示。状态不代表服务端授权或能力开通。
- 演示步骤仅为可见操作摘要，不展示模型隐藏推理；计时器有取消、卸载和过期结果保护。
- 工作区渲染 `OperatorArtifact` 的已知语义类型，支持清单、指标、时间表、比较等差异化结果。不执行模型提供的HTML、脚本或React源码；后续扩展格式先增加受控渲染器。
- 附件只保留文件名、类型和大小，不上传、不读取内容。复制与下载均为当前示例结果。
- 确认仅生成本地演示回执；不会创建预约、履约任务、资金处理或发送通知。
- 自动化任务支持本地新增、编辑、删除、开关与运行演示。没有后台调度，关闭页面或到达计划时间不会执行。
- 后续接入需补充授权能力目录、模型流式会话、工具调用状态、业务确认与真实执行回执；所有资金以服务端业务结果为准。

## 响应式

宽屏使用原可拖动双栏，收起不会重挂聊天输入。1050px及以下默认收起工作区，按钮打开原Drawer；对话保持一份。插件卡片自适应列数，任务操作在窄屏换行。
