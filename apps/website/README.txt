Rental OS 静态官网复刻包

使用方式：
1. 保持 index.html 与 assets 文件夹在同一级目录。
2. 本地预览建议通过静态服务器打开（Hero 轮播清单需要读取 JSON）。
3. 也可将整个目录上传至任意静态服务器、GitHub Pages、Nginx、OSS/CDN 等。
4. 页面使用远程 Inter 字体和 Iconify Ant Design 图标，不新增本地字体文件。

说明：
- 已按参考效果图重新组织为可响应式静态 HTML。
- 图片/UI 资源均来自重新生成的高清素材，不从原效果图直接截取。
- 桌面端为主还原，同时适配平板与手机。
- Hero 当前固定使用 `assets/hero-solutions-neutral.png`，不启用轮播脚本，也不保留其他背景图引用。
