## 1. 当前目标

后台内部经营链已经能够完成租户开业、会员、定价、报价下单、分配锁定、领取归还、异常、工单、资金和结算。当前只补真实试点需要的日常经营缺口，不重做已验收内核。

## 3. 推荐执行顺序

1. `SHARED-LOG-01A`，先补所有客户端共同依赖的配送规则。
2. `ORDER-CHANGE-01`，关闭已有订单变更的后台和客户端出口。
3. `PILOT-01` 与客户端真实 Provider 验收并行推进。
4. `CORP-SETTLE-01`、`DOC-PRINT-01` 根据首个试点是否需要企业账期和正式凭证决定先后。
5. 再选择 `CAMP-01`、`VEH-01` 或 `CON-01` 中一个真实品类，不并行铺开三个品类。

## 4. 任务更新规则

- 本文件不记录已完成任务和逐提交历史；完成后移入[统一归档](../归档/多品类租赁平台已完成任务归档.md)。
- API、数据库迁移和管理端页面属于同一后台任务时必须一起验收，不能只以页面存在或类型检查通过结项。
- 真实 Provider、法定票据、税率、电子签章和生产放行必须使用真实环境证据，模拟结果不得代替。
