# CAT-GOV-01 实施基线与迁移设计

日期：2026-09-30。依据：《平台租赁品类管理与版本发布专项需求说明》v1.1。本附件记录代码与静态基线；不声称数据库、浏览器或小程序宿主已经验收。

## 现状和迁移入口

| 入口 | 当前来源 | 目标入口 / 风险 |
| --- | --- | --- |
| 租户及空间创建 | `platform.service` 固定四品类枚举、`platform.repository` 字符串映射 | 从发布版本与开通/采用政策解析；创建事务内绑定版本，不能落空壳 |
| 核心报价和建档 | `rental-core.service` 进程内 `RENTAL_CATEGORY_DEFINITIONS` | 以空间绑定版本读取；旧报价/订单以自身引用和快照执行 |
| 能力治理与 Hook | `workspace-capability.service`、`capability-hook.runtime` 再读静态必选能力；仓库另读品类表默认值 | 与核心共用解析服务；代码只登记真实实现和硬前提，避免双口径 |
| 后台导航及资料 | `navigation.tsx`、`WorkspaceSwitcher`、会员资料页及建单页含固定映射 | 安全元数据驱动；图标提供受控通用回退 |
| 客户及员工端 | shared/client 与 API 元数据、端侧可能含四品类映射 | 消费授权空间的安全投影；不暴露治理正文和内部规则 |
| 数据模型 | Prisma `RentalCategoryCode` 为四值 enum，品类身份表持可变 JSON，空间仅有 `categoryCode`；另有 10 余处品类 enum 字段 | 先增兼容版本结构及引用，最后独立迁移动态编码与各事实字段；不得一步放开新编码 |
| Seed | `seed.ts` upsert 对既有定义执行 `update: category` | 改为只补缺身份/内置版本；演示事实与正式模板分离 |

共享 `core.ts` 的 `RentalCategoryCode`、静态定义、能力白名单和 `workspace-names.ts` 仍是四项；项目中 API/shared/admin 共 27 个文件含固定枚举或定义引用。不能仅更改平台列表 API 就声称新品类可营运。

## 基线证据与限制

- `npm run test:category-core` 在重新生成 Prisma Client 后通过：品类核心对齐，以及四品类的目录、定价分组、地点、价格、报价和规则契约。
- 首次运行因隔离工作树旧 Prisma Client 缺 `organizationId`、优惠券日期字段而在 TypeScript 编译阶段失败；`npm run db:generate` 后复跑通过。此为生成产物失配，不是业务差异。
- 该专项未覆盖本任务要求的每个品类的真实资产预占、取消、续租含缓冲、交接、结算和权限全链路。后续逐场景补真库/浏览器证据；不能将现有静态契约检查称为全部四品类经营验收。
- 当前只核对 Prisma schema 与迁移目录，尚未查询目标库数据或执行迁移。库中定义与静态模板是否漂移、事实数量与回填可行性必须在专用克隆库中逐项核对，冲突时停下，不覆盖任一来源。

## 设计决策与部署顺序

1. 复用 `rental_category_definitions` 作为稳定身份；新建草稿/发布版本和独立可修订的开通、版本采用政策。空间保存当前版本 ID 与采用修订号。发布正文不可更新；政策变化不回写正文，也不追改当前绑定。
2. v1.1 候选资料采用**独立暂存**：按空间、目标版本、来源采用修订和实体原修订保存有限的结构化型号/资产补丁。限制实体数、字段数及总字节；当前保存接口继续严格执行当前版校验。采用事务里锁定空间和受影响实体、复核资格/修订/唯一性/当前价格规则依赖，原子应用补丁、唯一声明、绑定和审计；失败保留暂存输入但不改变经营事实。价格/规则仍走各自草稿与发布。
3. 先添加兼容结构，确认旧程序可读写，再回填可证实的当前空间绑定。存量报价和订单没有历史版本证据的标记 `legacy`，保留原价格/规则/检查快照，不伪称曾采用当前版本。之后升级所有 API 与后台任务读路径，最后再迁移 enum 与开放动态写入。
4. 品类新开通政策与各版本的新建/升级/恢复资格分别校验。推荐版本是显式引用，不能取最新代替；停止新开通不禁止既有空间履约。恢复旧版也须兼容检查，不能删除升级后字段以求通过。
5. 动态写入开关默认关闭。记录最低兼容程序版本，并在所有 API/后台任务实例通过兼容性检查后才开放。产生动态事实后不得接入只识别四品类的旧程序；关闭开关不是数据回滚。数据库灾难恢复另需授权和资金事实核对。
6. 租户价格版本、规则版本和营业日历独立于品类模板：旧报价建单复制原快照；独立续租新增时段读申请时现价，原价补差读原依据，换货读所选价格基准，各自记录变更依据。不可拿“历史保护”一概冻结后续现价。
