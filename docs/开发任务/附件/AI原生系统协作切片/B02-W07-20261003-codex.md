# B02-W07 统一 AI Gateway 编排

基线：`57d17e3`。

## 实现

新增 `UnifiedAiGatewayService` 与 transport/audit ports。invoke 先经过 Router，再创建 durable admission、预算预留、审计事件，随后调用可插拔 transport；有 usage 才结算，无 usage 或派发失败进入 unknown 核对路径。stream 同样必须先经过 Router，并共享总 deadline/cancellation 边界。

本切片不直接暴露供应商、密钥或业务数据库，也没有把供应商 SDK 放进 Agent。既有 `ModelGatewayService` 仍作为低层协议实现，后续接线由显式动态模块完成。
