# AIN-11/S10：共享数量表示边界收口（2026-10-05）

## 实现

`budget-quantity.ts` 现在在预算仓储事务之前拒绝超过 `Number.MAX_SAFE_INTEGER` 的 token 数量。虽然 Prisma token 列是更宽的无符号 BIGINT，但当前冻结的 shared `AiUsageQuantityDraft` 以 JS `number` 表示；继续接受更大的值会导致写入后的读回只能经过不安全的 `Number(bigint)`，无法证明金额/用量事实没有变化。因此本切片选择明确拒绝，而不是截断、四舍五入或依赖数据库异常。

## 验证

- `tests/ai-native-budget-representation.test.cjs`：2/2 通过、退出码 0；连同 C01～C03 及 Gateway 合同回归共 18/18 通过。
- 覆盖 safe integer 边界、超边界输入，以及 `PrismaBudgetRepository.reserve` 在打开 `$transaction` 前拒绝。
- `npm run lint -w @rental-os/api` 与 `git diff --check` 均退出码 0；未连接真实数据库，未验证 MySQL BIGINT 行为。

## 接入影响

调用方若要支持超过 JS safe integer 的 token 量，必须先扩展冻结的 shared 数量契约为十进制字符串/BigInt 语义，并同步 Prisma 读模型；本切片不擅自修改 shared。当前拒绝是安全边界，不是把宽列能力宣称为已支持。
