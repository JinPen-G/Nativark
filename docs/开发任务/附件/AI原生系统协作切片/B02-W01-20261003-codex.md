# B02-W01 Profile 模型、仓储与 CAS

基线：`56a2058206323f0ebc8a84c1208dff1f50a7a73c`。工作树：`codex-ai-native-transition`，分支：`ai/ai-native-foundation-20261002`。

## 实现

- 在 Prisma schema 新增 `AiScope` 和 `AiProviderProfile`，支持 platform/tenant/workspace 所有者 scope、多 Profile、default/reasoning/vision/embedding 角色、platform_managed/tenant_managed、credentialRef、启用状态、能力白名单和 configRevision。
- 通过复合 scope 外键把 Profile 绑定到服务端建立的 scope；同一 scope 的 profileKey 和 role 均有唯一约束，避免用单一 tenant.model 字段覆盖多角色。
- 新增 `PrismaProviderProfileRepository`，实际使用 Prisma delegate 形状，list/get/create/update 均强制 scopeId + scopeKind；update 使用 `updateMany` 的 `configRevision` 条件进行 compare-and-swap，冲突返回 null，不覆盖他人的修订。
- credentialRef 仅存引用，不接收或返回明文密钥；仓储不提供任意 SQL 或无 scope 查询接口。
