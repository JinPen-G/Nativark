# B02-W06 预算预留与用量账本

基线：`aed6b18`。

## 实现

新增 `AiUsageReservation` 与 `AiUsageLedgerEntry` 持久化模型及 `UsageAccountingService`。预留按租户/幂等键和 callId 唯一；结算先写幂等账本事件，再进行条件状态转换；重复结算不重复记账。传输丢失进入 unknown，必须通过显式 reconcile 才能落账，不能自动释放或重发。

生产 adapter 接口要求数据库唯一约束和条件更新，未使用进程级 Map 作为一致性保证。本片测试中的 Map 仅为离线受控仓储替身。
