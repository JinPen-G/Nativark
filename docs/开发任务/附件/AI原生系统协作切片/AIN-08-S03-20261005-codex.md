# AIN-08-S03｜会员候选只读事实投影

## 交付

- 新增未注册的 `AiMembershipCandidateReadFactsService`，消费既有 `listPersonalOptions` 端口。
- 入口要求服务端解析的 workspace operator/staff 上下文及既有 `rental-os:order:create` 权限；不接受 caller 自报租户、空间或客户身份。
- 仅输出有界的 `customerId/name/phoneMasked/membershipStatus` 候选，不选择客户、不解析企业预约资格、不创建报价/订单，也不把候选列表当作可执行批准。
- Membership 端口缺失、抛错、返回越界或结构不合法时 fail closed；没有新增 HTTP 路由或公共 DTO。

## 验证与未验

命令：`node --test tests/ai-native-ain08-membership-candidate-read.test.cjs`、`npm run lint --workspace apps/api`、`git diff --check`，均需记录实际退出码。

本切片使用真实投影服务与受控 Membership/authority 端口；未连接真实数据库、HTTP、浏览器、模型或生产授权。`listPersonalOptions` 的真实请求上下文装配仍需主线在合法 Gateway/Controller 入口提供，未宣称 AIN-08 或 AIN 专项完成。
