# B02-W03 模型能力证据与调用前准入

基线：`2396491`。

## 实现

新增 `AiProviderCapabilityEvidence` 持久化模型与 Prisma adapter。证据绑定 profile、租户/空间 scope、能力码和 `configRevision`；配置修订后旧证据保留为历史，但不会参与当前准入。证据支持 supported、unsupported、unverified 状态和过期时间。

`ProviderCapabilityService` 提供证据记录、当前版本预检和必需能力断言：缺证据、非 supported、过期或修订不一致都会进入缺口，不会跨 profile 或跨模式回退。
