# AIN-06-S04｜取消请求的持久化结算边界

## 交付

- 运行器发现已持久化 `cancel_requested` 后，不再注册/执行新步骤。
- 当组合根提供 `AiTaskRunnerOutcomePort` 时，运行器提交 `cancelled` 聚合结果并用新 lease fence 释放；没有该端口时仍返回 `cancel_requested`，不把本地返回值伪装成持久化取消。
- 既有转换适配映射到 `cancel_settled`，仍由现有任务状态机检查未提交副作用；未知/已提交副作用不会被预算层或运行器声称回滚。
