# Fork执行线接口需求（2026-10-05）

基线124f5e80；独立树ai-native-fork-execution。主线/schema仍归主Claude，本文件是需求不是迁移或已完成证据。

## AIN-06 跨恢复累计限额缺少持久模型

现有AiTask/AiRun/AiStep没有累计模型调用次数、活动运行毫秒、输出字节，AiRun.startedAt/endedAt不能表示暂停后多段活动时间；不能只给runner传一个任意count或从step数量推算模型重试次数。

建议主线按唯一schema所有者提供：
- AiTaskExecutionBudget（scopeId/taskId复合唯一及外键）或AiTask上的等价字段：policyVersion、maxSteps、maxCalls、maxActiveMs、maxOutputBytes、consumedSteps、consumedCalls、consumedActiveMs、consumedOutputBytes、revision。计数使用unsigned BigInt或明确上限的unsigned int，API转number前检查safe integer。
- AiTaskExecutionCharge：task/run/step/action、fencingToken、独立chargeId/幂等指纹、资源kind、amount、状态，关联唯一(scopeId,taskId,chargeId)。调用前保守预留，领取/更新与任务/run锁按既有task→run顺序CAS，未知不释放。
- 不用requestId充当chargeId；model重试应关联主线真实invocation/预算记录，不能与AIN-11再扣一套货币额度。此处只限制任务运行资源。
- 旧行nullable/未初始化即关闭持久执行入口，不能默认无限。明确由可信场景政策建立限额，恢复不得覆盖为更大值。

建议本线消费的窄端口：load(taskId,lease)返回可信policy及计数；reserve(taskId,lease,chargeId,kind,amount)原子扣减；record/unknown绑定同一charge。实际方法/字段由主线按Gateway调用关联统一后给固定提交，本线再补adapter和重启限额测试。

## AIN-06 恢复/任务结果证据

本线可先用现有字段补授权步骤终态读取、同run/action/fingerprint绑定与任务CAS修订；未知步骤核对不得再次执行。正式command factory仍需主线持久plan/input/result证据源，尤其unknown与failed结果必须有合法resultRef，不得runner生成随意ID填空。

## 权限

新增内部动作（若本线实现）read_step_terminal、takeover_run需由主线真实权限adapter明确处理；未知动作默认拒绝。人工接管只允许显式授权的当前任务owner/同主体holder切换，不等同任意管理员跨用户共享任务。扩大任务共享需要独立契约，不能通过修改ownerWhere放行。
