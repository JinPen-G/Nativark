## 请求契约与复用链

请求路径前缀：`ai-native/text-capability`（宿主是否加 `/api` 由既有宿主决定）。全部 POST、200 成功响应、`Cache-Control: no-store`。

| 叶子 | 输入 | 行为 |
|---|---|---|
| `prepare` | `{requestKey}` | 只准备当前文本配置元数据；无输入写入、无密钥读取、无任务启动 |
| `original/publish` | `{requestKey}` | 先原键读回；不存在时才发布服务器固定命令；不建任务 |
| `original/read` | `{requestKey}` | 原键读回；缺失返回 not_observed/retryable:false，不补写 |
| `task/create` | `{requestKey}` | 从持久原输入取得 inputRef，稳定派生 creationKey，调用既有任务生产者 |
| `task/read` | `{requestKey}` | 只读原创建回据；不创建替代任务 |
| `task/start` | `{requestKey}` | 唯一显式执行入口，调用原持久 workflow.startOriginal |
| `task/inspect` | `{requestKey}` | 原任务/run 状态投影；不输出 fence/registration/输入正文/结果正文 |
| `task/cancel` | `{requestKey,expectedRevision}` | 原任务动作政策及 CAS；仅 cancel_requested，不宣布 cancelled/退费/回滚 |
| `task/reconcile` | `{requestKey}` | 原持久恢复入口，只核对原执行，不生成新键或替代任务 |
| `receipt/read` | `{requestKey}` | 原 workflow.readCapabilityReceipt；可能写 capability evidence，故为 POST；不注册/预留/派发 |
| `preflight` | `{requestKey}` | 原 command 的当前文本 preflight；allowed 不等于派发许可 |

每请求只有 Bearer authorization 被采纳。requestId 由服务器生成，audience 固定 operator；真实 AuthService 重读当前会话与工作空间，TenantModelConfigurationAuthority 复用管理 Guard；await 前后复核当前身份/权限/作用域，controller finally 清空凭证并移除请求 aborted / 响应 close 监听。只有 response 尚未 writableFinished 的提前关闭触发执行 abort，不把正常完整 body/response close 当作供应商回滚。没有另造 sessionId 证明。请求体拒绝 actor/tenant/workspace/lease/holder/fence/registration/command/profile/model/price/limits 等额外字段。

平台 profileId、场景版本、priceVersion、持久 calls pricing、host 参数均来自服务器依赖；limits 来自既有持久 plan policy，不能从 HTTP 提供。新入口不注册 AppModule，不 seed plan/action policy，不自动启用模型。

任务结果仅是任务结果；能力 supported 仍只能由原文本 live verifier 验证。回据投影保留原 methodVersion、mock/live 模式、配置修订、checkedAt/expiresAt；无观察时 observation=null，模式标签本身不证明支持。mock 不证明 live，非文本不走此入口也不借用文本结果。未知写回包为 AI_RESULT_UNKNOWN/retryable:false，nextAction 指向原键读回/恢复操作；不包含异常原文或密钥。
