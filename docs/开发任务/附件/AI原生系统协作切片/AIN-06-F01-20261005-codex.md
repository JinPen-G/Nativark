# AIN-06/F01：接任整合后的运行器修订传递修复

日期：2026-10-05。作者：Codex；依据接任主力授权。源码基线 `aaa33cc4`，关联AIN-03/06；不是AIN-06结项，也不替代AIN-05先决闭环。

## 复现与实现

- 实际 `AiStepRegistrationRepository` 在登记事务中推进run revision，原运行器适配丢弃该值，使下一次 `AiStepTransitionRepository` CAS仍使用旧revision。新增测试以原事务模拟夹具调用两个真实仓储和真实runner适配器，复现 `undefined !== 6`；补传runRevision，运行器继续使用最新修订。
- recovery编排标志原样传给严格领取接口；新增负例复现多余字段。领取时剥离编排标志，其他输入仍交仓储严格校验。
- 已持久化failed结果不应最终返回succeeded；修正执行和核对分支，失败终止后续步骤并保留错误码。核对分支持久化后的lease/taskRevision也同步传至释放。
- 同步抛错的effect原先遗留deadline计时器；显式捕获并释放自身计时器，不执行第二次effect。
