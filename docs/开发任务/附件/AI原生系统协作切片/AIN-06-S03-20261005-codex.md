# AIN-06/S03：运行器结果到既有任务仓储的装配适配（2026-10-05）

## 实现

新增 `ai-task-runner-outcome-adapter.ts`，把运行器的成功、失败、未知和明确暂停原因映射到现有 `AiTaskTransitionRepository` 的任务状态/原因枚举。适配器只调用现有仓储和由组合根提供的 command factory；它不复制状态机，不生成授权，不创建业务动作。仓储返回的任务 revision 必须正好前进一版，run fencing revision 必须前进，否则适配器拒绝结果。

暂停保留 `input`、`confirmation`、`external` 语义；unknown 只进入 `waiting_external/external_pending`，不变成成功或可盲重试。真实授权、task scope、step 状态一致性仍由现有任务仓储负责。

## 验证

- 新增适配器行为测试：状态/原因映射和非法 revision/fence 拒绝。
- 运行器自身调用该端口的回归与 API 类型检查在提交前执行。
- 测试使用受控仓储替身；未连接数据库、未启动 worker/API、未验证真实 MySQL 锁和宕机恢复。
