# AIN-05/S09 受控HTTPS增量流与协议Adapter接线

2026-10-03，负责人12里程碑长包；本树codex-ai-native-transition、ai/ai-native-foundation-20261002，起点fffa012。承接既有传输和decoder，不新增平行Gateway、厂商SDK或公共DTO。

## 生产实现

- ModelEgressTransport.postStream复用post的performPost安全链：检查URL/全部DNS、公网地址pin、TLS hostname校验、禁代理/重定向、header/request/response上限、UTF8、总传输timer与AbortSignal。
- 返回headers/bytes内部事件。异步队列最多256项、byte budget不超过响应限额；复制bytes防可变buffer污染，producer洪泛拒绝而不是无界缓存。消费者return/取消关闭request与response、清timer；不合作迟到DNS不派发。
- ChatCompletionsAdapter.stream实际发送stream=true/include_usage，通过增量SSE decoder返回text_delta，再在stop+DONE+EOF验证后返回内部result；不把partial当成功。首个delta在body end前到达，不是生成结束后回放。
- 构造的transport有postStream时才声明内部streaming capability；仅post传输不宣称stream能力。tools/structuredOutput仍不宣称，明确CAPABILITY_UNSUPPORTED。
- decoder增加密钥前缀暂存：跨delta的secret可能前缀不提前吐出；完整echo在输出前拒绝；被证明普通文字或合法结束后释放。UTF8跨块/SSE边界、重复usage/DONE、截断及缺终止沿用严格校验。
- ModelAdapter的stream与事件为内部协议接口，不是统一C03 Gateway/任务完成事件。旧generate仍不能绕过将来的Router/admission/预算接线；不向AppModule默认注册stream。
