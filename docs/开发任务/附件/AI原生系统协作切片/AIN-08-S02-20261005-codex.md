# AIN-08-S02｜可用性只读事实投影

## 交付

- 新增未注册的 `AiAvailabilityReadFactsService`，复用 Rental Core 现有 `availability` 计算入口；服务端授权返回 workspace operator/staff user 后才允许读取。
- selected 地点范围在调用 Core 前拒绝越界地点；输入严格限量，Core 返回的 available、数量和 reasons 原样验证后投影。
- 明确该入口只做可用性预检，不是库存预占、订单创建或支付；不接受模型/客户端权限声明。
