## 追加修复：可用性结果绑定（2026-10-05）

发现只校验地点和时间会接受与请求行不对应的 Core 返回，导致空结果、错商品或错需求量可能被包装为权威可用性。AiAvailabilityReadFactsService 现在要求返回行数与请求一致，并按位置核对 itemGroupId 与 requestedQuantity；不一致统一拒绝为 INVALID_RESPONSE。新增行为测试覆盖错商品和错需求量，未改变 Core 的库存计算。

验证：node --test tests/ai-native-ain08-availability-read.test.cjs（3/3，通过）；git diff --check（通过）。本次仍为函数级/离线证据，真实 HTTP、数据库并发、浏览器与生产装配未验。

追加目录绑定防护：目录投影现在拒绝 Core 返回的重复 id 或 code，避免非唯一行被误当作可核对目录事实；新增行为测试，未改变 Core 查询或排序语义。
