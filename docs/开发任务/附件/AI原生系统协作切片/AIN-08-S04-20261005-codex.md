# AIN-08-S04｜只读业务入口受权桥

## 交付

- 新增未注册的 `AiBusinessReadRouteAuthority`，把品类、可用性和会员候选只读投影绑定到既有 `ApiAuthGuard` 路由语义。
- 路由由服务端固定，输入只作为受控请求体；tenant/workspace/actor/audience 来自当前 Guard 会话，不接受输入 scope。
- 读取在 Guard 建立的身份上下文内执行，并在结果返回前重新建立并比对授权指纹；这仍是顺序复核，不宣称数据库/Guard 原子授权事务。
- 不新增 Controller、路由、权限、公共 DTO 或业务写入口；缺凭据、身份类型不支持或授权失败时 fail closed。
