# AIN-11/S09：持久预算 Gateway 接入边界（2026-10-05）

## 实现

新增 `apps/api/src/modules/ai-native/budget/budget-gateway-adapter.ts`，提供显式的 `BudgetGatewayLifecycle`。它通过 `BudgetGatewayBindingSource` 在每次 reserve、dispatch、settle、release、unknown、reconcile 前从可信服务端来源解析完整的 task/run/step/action、actor、scope、配置修订、价格版本和场景关联；适配器自身不保存授权/关联 Map，也不把旧 Gateway 的 `requestId` 复制成运行关联。

结算只接收持久化 `evidenceRef`，不把 provider 返回的 token 数或调用者字符串当作已派发/已用量证据。跨租户/空间/主体绑定在调用预算服务前拒绝。旧的 `GatewayPorts.budget` 仍未被改写或伪接入，因为它没有携带这些必要关联，继续保持显式未接通。

## 交接与边界

- 主线接入需要提供 `BudgetGatewayBindingSource` 的真实实现：reserve 时按授权 task/run/step/action 和 scene 解析；其余操作按 reservation ID + 当前授权上下文读取同一持久关联。
- `evidenceRef` 必须来自持久 dispatch/usage evidence，并由预算模块再次校验 reservation、调用、主体、scope、configRevision、priceVersion 和 dispatch token。
- 这不是旧 `UsageAccountingService` 的替代注册，也没有修改 Gateway、AppModule 或生产开关；在主线未接入前不能宣称 AIN-11 或 Gateway 单账已完成。
- 测试为离线服务边界/受控替身，不证明 MySQL 事务、跨进程并发或真实 Gateway/模型链路。
