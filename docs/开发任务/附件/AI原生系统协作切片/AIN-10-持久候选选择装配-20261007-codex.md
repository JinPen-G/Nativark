# AIN-10 持久候选选择装配

Codex临时顶替Claude主线，施工树 `.claude/worktrees/claude-ai-native-foundation`、分支 `ai/ai-native-contracts-s01-20261002`，源码基线 `06c5cd1a`。这是原AIN-10持久知识依赖接线，不是新阶段，不修改公共协议/ACL语义/生产启用。

## 实际实现

- 新增 `PrismaKnowledgeSelectionAdapter`，使用真实生成Prisma delegate类型查询当前workspace内published文档元数据；SQL包含tenantId/workspaceId/status，id确定排序、take101，投影仅id/tenant/workspace/status。超100、重复、跨scope、畸形结果拒绝，不静默截断成完整结果。
- 调用既有真实PrismaKnowledgeRepository读取并核验当前JSON/关系字段；候选逐份通过宿主提供的当前KnowledgeAuthorizationPort，拒绝的文档不会进入正文查询。grant完整绑定actor/audience/scope/accessKey；await期间context、文档、grant修订变化拒绝。
- 授权后复读revision和文档状态；返回只有documentId/documentVersion/aclRevision的既有约束。既有Retrieval、Source、缓存与ReadAdapter继续重授权、检查当前版本及撤回，候选选择并不构成永久授权或原子授权。
- createPersistedKnowledgePorts在未提供selection时显式装配此适配，传入selection的旧组合保持兼容；缺findMany或授权依赖仍拒绝。不会注册AppModule/HTTP/Cron。
- 自查纠正提前过滤未索引文档会掩盖原not_ready/failed语义的问题：选择器不重写解析/索引状态机，原检索服务决定是否读取正文及公开就绪状态。

## 接线与剩余

显式 `composePersistedKnowledge` / `KnowledgeModule.register(createPersistedKnowledgePorts(deps))` 继续使用原文件、当前授权、记忆授权、Gateway、cache、policy、clock依赖；selection可省略但DB必须支持真实findMany。

仍缺正式知识ACL授权grant生产者/权限与权益目录、合法附件生产来源、真实人工确认来源及生产接线。现有AiKnowledgeAcl字符串字段不等于已定义官方subject/permission规则，本轮未猜规则或给予默认权限。workspace以外tenant/platform知识未提供存储查询回退。词法搜索不是向量搜索；超过100候选需后续正式分页契约或受控候选策略，目前unavailable。

只有类型、离线真实服务行为与数据库执行模拟证据；MySQL并发/迁移、真实HTTP/模型、浏览器/微信/真机/生产、独立Review均未验。无schema或迁移变化，无生成共享产物。作者自查不是独立审查，不结项AIN-10或M1、不改原任务完成率。未跟踪output全部保留。
