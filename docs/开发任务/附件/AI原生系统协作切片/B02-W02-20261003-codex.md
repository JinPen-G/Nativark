# B02-W02 双轨配置与旧 BYOK 兼容

基线：`ac8c2006ed7c151786de1747b6240b222cae43df`。

## 实现

新增 `PlatformModelConfigService` 双轨门面，复用已有 `TenantModelConfigService` 的授权、CAS、SecretBox 密文绑定和 retain/replace/clear 逻辑：

- 无租户配置时只返回 `platform_managed / Rental OS AI / not_verified`，不返回平台 URL、key、model。
- 旧配置缺少 mode 时保持 tenant_managed，不重写、不迁移密钥。
- 切换到 platform_managed 只隐藏租户供应商配置，保留密文；切回 tenant_managed 前重新验证密文绑定。
- 租户只能保存自定义服务，平台服务的实际 profile/凭据由后续 Router 和平台 profile 仓储提供，不接受租户伪造 platform 配置。
- 对外摘要不包含 API key；已有 revision CAS 保持并发冲突拒绝。
