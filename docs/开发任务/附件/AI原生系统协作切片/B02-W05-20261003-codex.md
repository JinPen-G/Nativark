# B02-W05 持久化 invocation admission 状态

基线：`3d6df76`。

## 实现

新增 `AiInvocationAdmission` 模型、迁移和 Prisma adapter。记录按租户、空间、callId 唯一约束，保存请求哈希、profile、有效期和 dispatch 状态；状态包含 admitted、revoked、cancelled、completed、unknown。

`InvocationAdmissionService` 对重复相同请求幂等返回，哈希不同拒绝；终态不可重放；unknown 只能进入显式核对/取消路径，不能被当作可安全重发。真实 adapter 使用数据库条件更新，避免进程 Map 作为一致性保障。
