# AIN-05 / AIN-19 公共媒体 Gateway 主线接线

## 本片范围

本片将已声明的图片输入从统一 Gateway 的公开意图入口接到内部模型协议，并保持原有 dispatch、预算、usage、unknown 和审计生命周期不变。媒体引用只接受 `attachmentId + attachmentRevision`，由宿主注入的授权解析器根据当前身份、租户、空间、版本和 ACL 产生受控读取绑定；模型或客户端不能直接提供 URL、storage key 或字节来源。

图片仅在路由 profile 声明 `vision` 时可用，音频暂保持 unavailable：当前 profile 能力与持久化角色没有正式 audio 能力，不能用 image/vision 伪装音频支持。解析后的内容必须有受控媒体类型、大小上限和 SHA-256 校验，并沿唯一 Gateway accounting/dispatch 路径执行。附件读取完成后会用同一上下文和引用再次复核授权，读取等待超时由 GatewayDeadline 中止；媒体数量上限在读取前检查。

## 入口与文件

- `prepareGatewayIntent`：解析公开意图并生成有界内部协议请求。
- `AuthorizedGatewayMediaAttachmentResolver`：组合当前授权解析器与服务端读取绑定，拒绝跨上下文、版本不一致、哈希不匹配或超限内容。
- `UnifiedAiGatewayService.invokeIntent/streamIntent`：把图片意图送入现有统一准入、派发和计量路径。
- `PublicAiGatewayService`：检测媒体内容并选择媒体意图入口；文本路径保持原行为。

## 未完成与主线接入要求

当前没有正式 audio profile 能力，音频继续 fail closed。实际文件存储和 ACL 生产者需要实现 `GatewayMediaAttachmentAuthority` 与 `GatewayMediaAttachmentBytesReader`，并由模块装配注入；本片不假造默认授权或存储成功。shared dist 导出缺口需由公共契约维护者修复后再复验全套消费者。
