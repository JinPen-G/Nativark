本片复用两端既有 `ai-task-workbench`、`AiPollingController`、cursor adapter 与 host action 入口，没有复制任务状态机或增加服务端 DTO。新增 `tests/ai-native-b14-c-recovery.test.cjs`，直接挂载实际组件逻辑并以可控 Promise 驱动：

- unknown 且无 `reconcile` 处理器时保持待核对/不可用；
- 读取失败不转成成功；
- 确认回调拒绝可见，任务仍保持 waiting_confirmation；
- 两个 Workbench 实例的 task/context/pending 状态互不污染。
