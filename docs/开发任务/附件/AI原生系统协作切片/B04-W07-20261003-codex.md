# B04-W07｜人工确认交互外壳

`HumanConfirmShell` 仅提供阅读勾选和宿主回调外壳。available/expired/submitting 与版本变化控制本地勾选；版本变化会清空旧选择。组件不生成 approvalId、不创建确认记录、不发请求，宿主没有可用状态或回调时不可确认。提交回调只接收 proposalId 与当前 revision。

验证：`node --test tests/ai-native-b04-human-confirm-shell.test.cjs`，真实 React 静态渲染 2 项；未验证浏览器版本变化交互、后端确认消费、授权链或并发提交，作者完成后待独立复核。
