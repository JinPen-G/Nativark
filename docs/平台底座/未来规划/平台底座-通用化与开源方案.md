## 2. 未来外部团队复用目标

外部团队能够接入自己的身份、权限、业务工具和正式执行服务，按需复用公共SaaS实现与AI Native能力，不必依赖租赁订单/库存/资金或更换其已有登录、组织、文件、订阅和支付系统。

- 可提供平台公共实现，也允许通过可信适配使用宿主已有能力；不重复建立第二套身份/客户/订阅/支付事实。
- AI是可选能力。普通Core不需模型即可运行；使用AI时，任务推进、Gateway、预算、批准关联与恢复机制复用，具体业务决策仍由宿主正式服务负责。
- 外部宿主可以没有Rental经营空间，但必须提供明确、可验证的资源范围与隔离，不把缺scope当全局权限。
- 公共合同不泄漏租赁实体、框架或Provider类型；宿主组合引用行业服务合理，通用机制不应为启动而加载行业实现。
- 外部接入不意味着任意URL工具、脚本/SQL执行或插件市场。适配器需可信安装与运行授权，未知工具和缺授权/权益/证据均拒绝。

这些是后续产品化方向，不承诺当前已支持外部身份系统、跨语言或任意数据库。PCH首期先通过现有技术栈的独立模块和非租赁样例证明边界，不等待所有未来组合。

## 3. 开源范围与发布前置

开源前需要负责人明确：

1. **发行范围：** 仅AI Native通用能力、公共SaaS实现、接入合同/样例，还是组合发行；PCH工程范围不自动决定开源范围。
2. **宿主信任边界：** 身份签发方、标识命名空间、资源归属、授权撤销与调用委托。客户端/模型不能自报主体或跨宿主授权。
3. **支持组合：** 平台/Core/合同版本、运行环境、持久化及最低回退；不以本仓同进程通过宣称跨服务已支持。
4. **许可证与权属：** 原源码、引用实现、第三方SDK、UI资源及示例的许可，品牌/商标和商业服务边界；未核验不能发布现有整个仓库。
5. **维护责任：** API兼容承诺、升级/弃用流程、漏洞报告和修复政策、发布签名与依赖锁定。
6. **材料审查：** 排除真实凭据、租户数据、敏感示例、历史output及商业资料；不能批量复制工作目录作为发行包。

先有PCH实际接入、Rental兼容和独立接手证据，再评估外部组合。许可证、仓库/包发布、网络、签名及生产启用均需当轮授权，不能由文档里的“开源目标”推出。

## 4. 外部化的数据与恢复条件

同进程模块与独立远程服务分开验收。若后续跨进程：

- 原同库事务的“批准消费＋业务提交”不会自动保留；必须明确可靠提交、幂等、原收据查询、失败补偿及当前授权，不以普通HTTP重试替代。
- 身份/租户映射、任务状态、批准消费、模型账、知识/文件ACL与删除标记各自迁移；聊天删除不删除业务事实。
- 知识正文、引用、外部副本/备份及删除传播有明确所有者；文件引用不等于访问许可。
- 在途任务优先固定原实现排空；只有状态、输入、批准、原账和收据映射已验证才允许迁移，unknown不能换宿主/Runtime/Provider重发。
- 回退前停止新路径准入并核对唯一执行者和数据兼容；回退不撤销已提交业务，不重复批准/扣费，不因切开关接回不兼容旧worker。
- 请求指纹、金额/数量精度等公共工具的迁移保持原规范化算法和历史版本；搬目录不改变旧幂等比较。

保留原实现、测试及兼容入口，不能以“Git能恢复”代替实际保留。模型调用预算、商业订阅收费与行业资金仍分账；受控本地自付模型例外沿原专项，不借本地Key替服务端调用。

## 5. 产品化验收要求

除PCH首期合同/样例验收外，公开对外支持的每种宿主组合须有独立证据：

- 按公开文档和固定产物接入，外部团队不依赖作者私有环境或聊天记忆；必需/可选能力、配置、迁移、失败恢复和停用可操作。
- 业务Core可不依赖AI运行；AI组合另验“目标→受权事实→方案→必要批准→正式执行→原结果核对”。
- 缺依赖、撤权、重复、崩溃/迟到、unknown及跨范围访问不绕过宿主安全；模型经唯一Gateway与预算单账，恢复不重置任务资源。
- 静态/类型、离线、真库、真实宿主、模型/供应商和部署分别登记；演示不称生产验收。

不预估未经测量的节省比例或接入时间。外部产品化是独立工作，不是“复制目录即可开源”。

## 6. 设计参考

- [Microsoft：Anti-Corruption Layer](https://learn.microsoft.com/en-us/azure/architecture/patterns/anti-corruption-layer)：宿主与行业模型隔离，不预设独立服务。
- [Martin Fowler：Monolith First](https://martinfowler.com/bliki/MonolithFirst.html)：先建立可验证模块边界，再依据需要外部化，不替代事务与验收要求。
