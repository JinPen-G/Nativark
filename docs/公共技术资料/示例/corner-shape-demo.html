左边是普通圆角（圆弧），右边加了 corner-shape 平滑圆角（超椭圆）。拖动滑块感受差异；下方 SVG 叠加图在任何浏览器都能看出区别。

参数

半径沿用后台 8–20 档位区间；平滑度 k 即 CSS superellipse(k)：k=1 是普通圆角，k=2 是 squircle。

① 真实 CSS 效果

这是实际写进后台会生效的样式。若你的浏览器不支持 corner-shape，右侧会和左侧一样——看下面第 ② 节。

border-radius（圆弧）
+ corner-shape: squircle

⚠ 当前浏览器不支持 corner-shape，右侧退回普通圆角（这正是不支持时的真实回退效果）。

② 形状数学对比（SVG，任何浏览器都一致）

同一半径下，圆弧（虚线/灰）与超椭圆（实线/紫）的轮廓叠加。紫线在直边附近更贴合边缘、在对角处更饱满——这就是“更平滑”的来源。
