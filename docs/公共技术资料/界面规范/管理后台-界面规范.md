# 管理后台界面规范

版本：v3.35｜维护日期：2026-10-27｜适用：租户后台、SaaS 平台后台

本文规定视觉基础、页面结构、组件复用与交互验收。**必须**为交付要求，**建议**为推荐做法；现状与目标不一致的部分必须记录，不能视为已达标。业务规则、权限和资金口径仍以正式需求与业务契约为准。

## 1. 技术与组件基线

### 1.1 设计原则

- **任务优先**：突出当前对象、状态和可执行动作。
- **层级明确**：主信息突出，辅助资料降级，重要限制常显。
- **一致复用**：共性尺寸、颜色和行为由共享层维护，页面不另建一套。
- **适度留白**：以对齐、间距和分区组织内容，避免重复标题、提示和外框。
- **事实准确**：不伪造数据、进度、成功结果或尚未接入的能力。

### 1.2 组件职责

| 层级 | 职责与入口 |
| --- | --- |
| 基础视觉 | UIArc 原组件及 foundation；保留源组件样式和动效 |
| 业务适配 | [统一组件入口](../../../apps/admin/src/components/ui/index.ts)；处理值、校验、权限、主题、本地化与兼容回退 |
| 表单与上下文 | Ant Design；保留表单状态、校验、禁用、ref 及复杂业务契约 |
| 组合表格 | Tablecn 外观、TanStack 数据模型、Motiq 数据动效；由共享 Table/DataTable 封装 |
| 页面装配 | 查询、字段、操作与布局；复用共享组件，不复制组件实现 |

后台使用 React/Vite，不引入第二套后台框架。请求与缓存分别复用 [http.ts](../../../apps/admin/src/api/http.ts)、[queryClient.ts](../../../apps/admin/src/app/queryClient.ts)。

组件是否已适配、仍需兼容或尚未验收，以[组件清单](../../../packages/ui-arc/COMPONENTS.md)为准。公开源码备用不等于已接入；Pro 源码须先取得许可。

[Animate UI](https://animate-ui.com/docs/primitives)可作为补充来源。按具体业务选择组件或反馈动效，核对版本、依赖和许可，适配现有主题、尺寸与减少动态偏好；同一交互仅由一套动效负责。

| 内容 | 维护位置 |

Token 按“基础值 → 语义角色 → 组件适配 → 页面消费”使用。新增共性需求先补共享层；同一角色的所有消费者同步生效。页面可定义业务特有列宽与布局，不得覆盖通用控件或 vendor 动效。

## 2. 主题、颜色和圆角

### 2.1 颜色与层次

后台主色读取登录账号的 `accountThemeColor`；租户客户端品牌色独立维护。未配置时采用 UIArc 中性色体系，平台默认主色为 `#353535`，深浅色由现有主题解析。

| 语义 | 使用规则 |
| --- | --- |
| 主色 | 主操作、选中和交互强调，不承担全部业务状态 |
| 文本 | 主信息使用前景色；补充资料使用 secondary/meta，不靠降低整组透明度弱化 |
| 背景与边框 | 页面、表面、浮层、分隔各用对应语义；输入默认边框跟随 `--border` |
| 状态 | 成功、警告、危险保留原含义，并配文字或图标 |
| 阴影 | 主要用于浮层与临时层级，使用现有 shadow token，不给每个分区加阴影 |

页面不新增默认品牌色或主题色常量。默认输入边框可统一，hover、focus、错误、禁用仍须可区分。品牌图片、图表数据色与状态色分别管理，不统一反色或染成主色。

正文保持平面层级；普通列表不添加玻璃背景、着色外壳或多重描边。Solid Glass 仅为备用参考，不是当前页面默认材质。

状态颜色由 `ADMIN_STATUS_COLORS` 维护前景/底色配对，浅深主题分别定义，不从品牌色派生。成功用绿、处理中/信息用蓝、待处理/风险用琥珀、失败/危险用红、草稿/停用/取消用中性灰；必须同时保留业务文字，不仅靠颜色传意。普通状态文字与底色对比至少 4.5:1。兼容 Tag 与新表格状态共用配对，禁止页内写低对比的标签色。

同一状态区只设一层主标签。下方分配进度、费用提醒等辅助信息使用次要文字、400 字重，不再叠加另一枚彩色标签；必要待办保留语义图标和明确文字。异常、资金阻断、权限限制不能因视觉简化而隐藏。标签共用 24px 高度、12px 字号、500 字重及 6px 圆角上限，长内容可自然增高。

### 2.2 主题模式

账号菜单提供浅色、深色、跟随系统；内部保留 compact 兼容模式。偏好由现有 AppearanceProvider 管理，不在页面复制状态或新增主题算法。

主题、语言与圆角必须覆盖 Portal 浮层。任一模式均保留可辨识的文本、边界、焦点和危险状态；保存前预览不得显示为已保存。

### 2.3 圆角角色

| 角色 | 默认值 | 适用范围 |
| --- | --- | --- |
| container | 26px | 卡片、表格外框、通用弹窗、抽屉及操作菜单面板 |
| button | 18px | 按钮、页签、分段、菜单选中项 |
| input | 18px | 输入、数字、选择、日期控件及选择类展开面板 |

默认值来自 `ARC_DEFAULT_RADII`。分组值缺省时，先按解析函数兼容历史统一值，再回退平台默认；不把回退结果当新配置保存。当前常规设置范围为 8–40px，按钮另有 999px 离散档。

- 输入圆角统一由 input-radius.css 适配；选择、日期及其展开面板随 input，选项随 button。
- 表格外框、排序/列显隐面板随 container；不得借用按钮派生圆角裁切。
- 头像、圆形图标、开关保留自身形状。订单状态标签等受明确语义上限约束，不直接套用按钮极致圆角。
- 设置入口是否显示，不影响 token 解析与注入；不得在页面重新计算圆角。

## 3. 排版与尺寸

### 3.1 排版层级

字体使用 `ADMIN_FONT_FAMILY` 系统无衬线栈，不在单页额外加载字体。字号、行高、字重统一读取 `ADMIN_TYPOGRAPHY`。

| 角色 | 字号 / 行高 / 字重 |
| --- | --- |
| 页面标题 | 20 / 28 / 600 |
| 页头范围提示 | 12 / 20 / 400，与辅助资料同角色 |
| 分区标题 | 16 / 24 / 600 |
| 面板标题 | 14 / 22 / 600 |
| 正文与字段标签 | 14 / 22 / 400 |
| 辅助资料 | 12 / 20 / 400 |
| 表格金额数字 | 16 / 22 / 600 |
| 指标、登录标题 | 24 / 32 / 600 |

表格金额的币种使用辅助字级与次级色，数字与币种同基线。关键金额、错误和业务状态不得因截断或缩小字号丢失；缩略内容须有键盘和触屏可用的完整查看方式。

### 3.2 控件密度与宽度

| 密度 | 高度 | 场景 |
| --- | --- | --- |
| 常规 | 36px | 单行输入、按钮、列表筛选与刷新/排序/列显隐 |
| 紧凑 | 32px | 行内操作、紧凑控件及浮层内原定结构 |
| 大号 | 40px | 有明确层级需要的主要动作与专用场景 |

分段控件与 Tab 轨道按**整体高度 36px**计量，内按钮扣除源 track/frame 边距；不要只改内按钮导致外框更高。Tab 的几何适配仅作用于导航外壳，不改变面板内字段尺寸或原动效。账号、导航、OTP、多行输入与编辑器按其专用结构处理，不强制拉成普通字段高度。

| 列表筛选宽度角色 | 默认宽度 | 使用约定 |
| --- | --- | --- |
| 综合搜索 | 280px | 常规可收至 200px；不为显示完整长占位文案而撑宽 |
| 状态、类型、普通选择 | 160px | 同用途统一，不随选中项长短跳动 |
| 单日期 | 160px | 保留完整日期与必要图标 |
| 日期范围 | 256px | 两端日期、分隔与清除入口必须可读 |
| 长名称选择 | 224px | 部门、地点、较长周期等确有内容需要时显式采用 |

上述数值为本项目档位，并非行业统一像素标准。规范原则是**按用途分档、按预期内容校验、按空间响应**，而不是所有字段等宽或逐页自行定宽；参见 [GOV.UK 输入宽度原则](https://design-system.service.gov.uk/components/text-input/#use-appropriately-sized-text-inputs)。

列表宽度由 `ADMIN_LIST_CONTROL_WIDTH` 维护，沿“基础字段 → 列表角色 → 组件适配 → 页面消费”应用；工具栏与“更多搜索”浮层共用角色，宽度规划与实际渲染必须读取同一值。自定义长选择通过 `ListFilterItem width="selectWide"` 声明用途，不硬写像素。状态等非关键长文本可省略并提供完整可访问名称/悬停文本；日期、金额等关键值不能裁切掩盖差异。

新增、编辑表单仍由栅格与字段分组决定宽度，沿用 `ADMIN_CONTROL_WIDTH` 的字段基准，不跟随列表收紧；浮层内可填满自身字段区域。列表条件不得自动铺满剩余空白；按钮继续按内容适配，高度与视觉中线统一。禁止修改 vendor 动效来配合宽度规范。

### 3.3 间距与对齐

优先使用 foundation 的 4px 间距体系。下列 px 为根字号 16px 时的对应值：

| 用途 | Token | 对应值 |
| --- | --- | --- |
| 同组细节、主辅文本 | space-1 | 4px |
| 图标与文字、相邻控件 | space-2 | 8px |
| 标题、Tab、列表工具栏至紧邻内容 | space-2 | 8px |
| 普通紧凑分区 | space-3 | 12px |
| 常规区块、表格边缘留白 | space-4 | 16px |
| 桌面内容左右/底部 | space-6 | 24px |
| 更大层级分隔 | space-8 | 32px |

正文顶部距上下文栏的共享间距由 `ADMIN_LAYOUT_SPACING.pageTop` 维护，当前为0；固定48px上下文栏内部使用 `contextOpticalInset=space-1`（4px）作光学校正，不增加行高。窄屏内容左右/底部使用 space-4。不在单页补负 margin 或私有顶部留白。

页头及页签使用以下固定角色，桌面与窄屏共用，不由页面自行调整：

| 关系 | Token / 来源 | 距离 |
| --- | --- | --- |
| 标题行最小高度 | 常规控件高度 token | 36px；不额外预留副标题空高 |
| 页头整体底边 → 首个 Tab、筛选或内容区 | ADMIN_LAYOUT_SPACING.headerContent | 8px |
| Tab 轨道底边 → 内容或独立渲染区 | ADMIN_LAYOUT_SPACING.tabsContent | 8px |
| 独立分区标题 → 工具栏、工具栏 → 表格外框 | ADMIN_LAYOUT_SPACING.listToolbar | 8px |
| 常规内容分区 | ADMIN_LAYOUT_SPACING.section | 16px |
| 同组控件 | ADMIN_LAYOUT_SPACING.inline | 8px |

`PageHeader` 统一拥有下方间距；内部 `view` 与外置内容使用同一值，外层不得再次叠加 Space gap、margin 或空节点。整页 `view` 与紧接页头的纵向 Space 使用块级布局，避免 inline-flex 基线额外撑出空白。纵向 Space 已管理分区间距时，内部工具栏取消自己的独立底边距；每段间距只由一层布局负责。

`ListSection` 的直属内容统一由分区 gap 排列，不再给告警、说明、表格或操作重复添加上下 margin。分区与相邻内容需要间隔时，使用 `--rental-layout-section-gap`（16px）；若父布局已管理这段间距，分区不再另加 margin。

Tabs 在共享适配层区分自带面板与外置内容，均消费相同间距，不改原滑块或进出动画。长标题、必要范围提示及多个操作可自然换行，间距从实际页头整体底边计算，不能硬锁高度裁字。多表分区、必要告警或编辑表单的实际高度不计为空白，不为追求“标题到所有表格都等距”而隐藏这些内容。

同一分区使用共同边线；表头文字与单元格正文起点一致，同类数值按业务精度采用一致对齐。组件内部间距沿原版，仅通过明确的公共适配调整。

## 4. 外壳、导航与响应式

### 4.1 外壳与品牌

[AppShell](../../../apps/admin/src/components/AppShell.tsx)统一管理侧栏、顶部上下文栏与正文滚动。应用侧栏采用 [Animate UI Base UI Sidebar](https://animate-ui.com/docs/primitives/base-ui/sidebar) 原版；源码、许可和固定版本见 [保留目录](../../../apps/admin/src/components/animate-sidebar/README.md)。收缩及浮层沿用原动效，中文菜单尺寸与状态在集成层统一适配；圆角按按钮、输入框、容器三组复用现有设置；不得另设固定圆角。整体保留原后台圆角外壳及内容面板。

| 项目 | 现行规格 |
| --- | --- |
| 桌面（≥768px） | 默认展开 240px，收起 48px |
| 移动端（<768px） | 18rem 宽度变量，保留原 Sheet 的 3/4 可用宽度与上限规则，正文占满 |
| 菜单/子菜单 | 统一 32px 行高、14px 字号，行间 2px |
| 分组/图标 | 分组名 24px 高，主菜单图标 18px |
| 收缩按钮 | 顶部内容栏左侧，28×28px，原 PanelLeft 动效 |
| 顶部上下文栏 | 展开/收起均为48px，与左侧空间切换入口对齐；pageTop=0，行内光学校正4px。以白色内容面板内缘为起点，平衡面包屑文字上下视觉留白，由ADMIN_LAYOUT_SPACING统一维护 |
| 空间/账号入口 | 48px 高度，32px 品牌标志或头像 |
| 用户弹出菜单 | 原 NavUser 类与定位，最小宽 14rem；不另改尺寸 |

面包屑保持单行并在可用宽度内省略；移动端详情路径优先保留上级页面与当前详情，省略最前面的业务分组，不能换行越出48px上下文栏。

Logo 下方保留真实菜单搜索；仅匹配当前有权访问的路由，输入时展开匹配分组。收起态按原版仅显示图标与 Tooltip，点击分类展开后访问子项；不再使用图标下方文字或边缘圆形收缩按钮。Ctrl/Cmd+B 沿原组件处理，输入时不抢快捷键。导航名称通常为 4–5 字，采用显示别名；完整页面名、品类术语、路径和授权保持独立。

侧栏 Logo 与 favicon 复用 [BrandIconProvider](../../../apps/admin/src/app/BrandIconProvider.tsx)：合法租户 Logo 优先，缺失或失败回退 rentalOS SVG，不用品类图片代替品牌。SVG 按既有规则适应深浅色，位图和彩色/复杂 SVG 保留原样。原版槽内完整展示品牌，不拉伸、不注入活动 SVG。底部账号使用示例默认头像；账号菜单只提供现有订阅、设置、主题、语言和退出操作，并保留权限判断。

侧栏与右侧内容面板圆角外露出的背景共用 `--rental-sidebar-surface`，以原侧栏的中性底色为准，深浅主题同步；去掉侧栏重复边框，不能让边框继承正文颜色形成黑线。菜单项、选中高亮和收缩按钮跟随按钮圆角，搜索跟随输入框圆角，账号/空间浮层跟随容器圆角；头像保留原形。空间下拉保留原 24px 图标槽与业务图标，顶部租户品牌仍使用 Logo。

顶部栏保留面包屑、时间与通知占位；原侧栏的宽度与内容标签过渡保持同步。原 Tailwind 变量、reset、portal 与深浅配色限定在侧栏范围，不能污染业务页或 UIArc；动效继续读取“外观与音效”的统一偏好。

菜单几何集中在 `ADMIN_SIDEBAR_METRICS`。当前页选中态使用账户主题色及配套对比文字色，选中背景平滑跟随路由移动，悬停采用中性底色；不得让鼠标移动改变当前路由标记。使用原 Provider 的 `animateOnHover=false`，避免焦点、展开状态和悬停项争抢共享高亮层；另用原 `effects/highlight` 受控 parent 模式承载当前路由，关闭其 hover/click 自动改值，保留原生 highlight 弹簧。高亮测量目标必须为触发按钮这一行，不能包含正在进出场的二级菜单；收起栏测量32px图标按钮，不能测量仍在收缩的整列。当前分组关闭或侧栏收起时，选中背景移至所属分类；搜索不含当前项时隐藏背景。收缩、展开、路由高亮和浮层动效继续读取全局动态偏好，减少动态时高亮直接到位。点击分类/进入页面分别使用既有按钮音/跳转音，遵守用户音量和静音设置，悬停无音效，快照点击回放不重复播放。

桌面收起态点击业务分类，在右侧打开原 DropdownMenu 二级菜单，不自动展开侧栏；选中页面后关闭浮层并保持48px收起态。浮层最小宽度使用 `ADMIN_SIDEBAR_METRICS.submenuMinWidth`（160px），条目至少32px高，跟随原主题、容器圆角和动态偏好。Enter/Esc、外侧关闭与焦点归还沿原组件处理；同一时刻只打开一个分类浮层。展开态和移动抽屉仍用内联分组。18px导航图标在32px按钮内上下、左右居中，隐形标签和折叠箭头不得继续占宽。

菜单和路由复用 audience、permission、capability 与品类判定。前端隐藏或禁用不替代服务端授权，也不得泄漏无权限对象的信息。

### 4.2 内容重排

- 使用可收缩网格与 flex-wrap；必要时设置 `min-width: 0`、`minmax(0, 1fr)`，避免最小内容宽度挤出工具栏。
- 列表搜索保持一行，空间不足时按优先级将末尾条件收进“更多搜索”，不堆叠成多排。表单与普通内容区仍按可用空间重排；不缩小文本或裁切操作适配。
- 数据表格在自身区域横向滚动，页面、筛选和分页不得随整张宽表溢出。
- 抽屉和弹层不得超出视口；保留关闭、提交与滚动入口，软键盘出现时重要操作仍可到达。
- 指标按内容区域宽度重排，不按整个窗口推断可用空间。五项概览在中等宽度采用3＋2均衡排列；八项报表默认4×2，小空间减为2列或1列，避免孤立尾卡和金额溢出。使用共享指标尺寸与间距，不为单页放大控件。
- 路由切换保留已加载外壳；身份、租户、空间变化必须按原 scope 清理状态与缓存。

## 5. 页头、内容与页签

### 5.1 页面结构

| 页面类型 | 推荐结构 |
| --- | --- |
| 单列表 | 页名＋主操作 → 筛选/工具 → 表格 → 分页 |
| 多分区查询 | 页名＋全局条件 → 有明确标题的业务分区 |
| 设置与编辑 | 页名＋保存动作 → 按业务含义分组的表单 |
| 详情 | 对象标识与状态＋主操作 → 事实摘要 → 明细/历史 |

每页只保留一个主标题。单列表不再重复页名或分页已有计数；多张表或不同业务区域保留有区分作用的标题。

多表页面每个列表保留一个二级名称，默认与本表搜索和工具同行，避免“名称一行＋工具一行”堆高页面。`ListSection` 的 `titlePlacement` 默认为 `auto`：内容从一张共享表格开始时，名称和 `extra` 操作自动合入该表工具栏，也适用于就绪的 `QueryState` 包装；不要求页面逐个开启。工具栏宽度不超过 720px 且有筛选或分区操作时，名称移到上一行，控件沿共享响应式规则收纳。每个分区只渲染一次名称和操作，保持二级标题语义与标签关联。

有摘要、表单、必要告警或多张表格的复合分区，名称保留在整体内容上方；加载失败或空态没有表格时仍须显示名称。必要时可显式指定 `above` 或 `toolbar`，但不以逐页特例代替默认规范。

普通列表使用无外框 `ListSection`，表格保留自身边框；真实填写区可使用容器。不得再用 Card 包住“搜索＋工具＋表格”或连续嵌套同义外框。

### 5.2 页头与说明

[PageHeader](../../../apps/admin/src/components/PageHeader.tsx)统一输出标题、路由图标及品牌浏览器标题。`extra` 放主操作，`view` 放独立视图或筛选；不把长筛选挤进标题行。

普通页头不使用独立副标题。`description` 仅用于必要的范围或风险提示，在标题旁以紧凑文字常显；空间不足自然换行，不截断。`note` 经 `InfoPopover` 按需展示普通详细口径。权限、资金后果、业务阻断和未接入限制必须就近常显，不得藏入帮助浮层；错误与成功结果放所属业务区域，不作为副标题。

删除“本页用于……”、重复操作说明及数据库、前后端、快照实现等开发文字。保留对用户判断有用的事实，例如“当前库存快照不代表区间利用率”。

### 5.3 页签与分段

Tabs 用于切换内容区域，Segmented 用于同一任务的视图或条件切换；只有真实先后依赖才使用 Steps。沿共享组件原选中滑块、键盘与滚动行为，不另造下划线或布局动画。

业务页签统一使用文字，不混用装饰图标。共享 Tabs 入口移除 `items.icon`，保持标签、禁用和面板状态；列表/卡片等纯图标视图切换保留独立的有名称按钮。

页签内容不再套重复边框。关闭、保留或销毁编辑状态按业务约定处理，不以视觉切换为由丢失未保存输入。

### 5.4 订单类详情

详情首先回答“什么订单、谁的订单、当前要做什么、何时取还、还需收退多少”。订单号、生命周期、客户、当前租期与资金摘要置顶；当前阶段操作紧随其后。待裁定费用、检查异常和结算阻断必须可见并能进入所属分区，不用装饰性进度条推测业务完成度。

正文按任务分区：**履约与商品、费用与资金、检查与处置、记录与单据**。同类信息集中；版本、计费依据、历史资源和业务助手按需查看，不抢首屏。单据保留打印及下载入口与原有法律属性说明。资料和列表不再逐块套 Card，真实编辑表单与必要告警保留容器。

| 信息 | 呈现与事实来源 |
| --- | --- |
| 取还计划 | 订单保存的地点及经营主体快照；当前应还时间沿已生效续租和承运租期投影，原约定时间保留辅助显示 |
| 费用 | 原订单应付、调整后订单应付、价内税、费用构成及裁定；押金和冻结额度不混入租金费用合计 |
| 租金费用账户 | 使用服务端应收、累计收款、累计退款、保证金抵扣与当前待收字段；不在页面重算净收、应收或续租差额 |
| 押金账户 | 目标、实收、已抵扣、已退与余额分开；余额不等于收入 |
| 预授权账户 | 应冻结、累计冻结、已转扣、已释放与剩余冻结分开；授权不等于已收款 |
| 流水 | 按实际发生时间倒序，同一时间保留原顺序，未知时间置后；不修改源数组，不由编号猜时间，不把失败事件当作成功收付款 |

无资金权限、读取中、失败和字段缺失必须区分，不能默认显示 0。真实零值正常显示。退款裁定只说明应收核减，不表示到账；模拟资金限制须常显。金额沿订单结算币种和公共精度工具，原始快照、权限、幂等、锁与确认流程不因重排改变。

详情几何使用 `ADMIN_DETAIL_LAYOUT` 和现行间距、排版 token：宽屏业务上下文与紧凑资金摘要并列，中窄屏纵向排列；账户字段和操作自然换行。复杂表格可在自身区域滚动，不能撑宽整页。

### 5.5 资料详情与侧窗的选择

个人会员、企业等需要反复查看、跨区块操作和关联历史的对象使用独立详情路由。对账批次、价格版本等需要宽表核对或版本比较的对象同理。侧窗保留给简单编辑、状态变更、授予、选择及依赖当前列表的短预览；不能把整套业务工作台塞进侧窗，也不把每个编辑动作机械拆成新页面。

独立详情采用 `RecordDetailLayout` 与 `RecordFacts`：页头显示对象名称、主要操作和返回列表，随后用状态条与紧凑字段交代当前事实，正文按业务任务分组或切换页签。常用联系方式、会员状态、企业人员概况或批次待办优先；技术编号、建档时间、依据和历史辅助呈现。无数据的辅助分区不保留标题及大块空状态，同一页签只呈现一个必要空状态。

- 个人会员：基础资料、账号与会员、地址、资质、实名认证、积分权益、订单及审计分区；服务端脱敏值、实名证据与单独权限保留。
- 企业：身份与会员状态常显；企业资料、员工、开票、合同及授信分区。列表和当前余额优先，新增/编辑表单由明确动作展开。未配置授信不等于零额度，也不等于读取失败。
- 对账：批次身份、总行数、差异与处理情况在前，行明细在后；确认差异不冒充支付或退款事实更正。
- 价格版本：版本、生效时间、变更依据与价格对比集中；恢复仍按原确认流程追加版本，不覆盖历史。
- 养护工单：工单号、状态、负责人及当前操作常显，处理结果与验收集中展示，历史单独查看；资源及证据引用辅助追溯。派工、提交、验收和取消仍走原权限及确认流程。

几何沿现行排版和间距 token，摘要字段宽屏四列、中窄屏两列；标签与长值可换行，表格仅在自身区域横向滚动。表单容器保留，资料和表格不增加外层 Card。页头到首段仍为 8px，独立业务分区使用 section gap，不再堆叠空白。

新路由须登记统一注册表、沿所属列表的权限/运行面与菜单归属，提供可直接访问、刷新和返回的稳定地址；企业任务页签可由 URL 定位。对象切换时关闭原编辑状态，不能把旧对象表单提交到新对象。未知对象、权限不足与读取失败不得回退显示其他对象或补造数据。

### 5.6 AI运营官工作区

- 入口位于侧栏概览上方，与「管理后台」形成模式切换。保留同一品牌、账号、圆角、主题和动态偏好；切回后台返回上次可访问的管理页。
- AI模式上部保留新对话、插件和自动化任务，下部按经营能力组织对话与最近记录。能力是否可见沿用相应业务页权限，不授予额外业务权限。
- 聊天复用用户提供的本地归档 AI chat，保留最近对话与新增对话顶栏，不叠加业务标题；输入框上层输入、下层附件/模型/发送，模型选择不在顶栏重复出现。右侧工作区使用原ResizablePanels，支持拖动、折叠与键盘。窄屏默认收起，通过工作区按钮打开Drawer，不并排挤压聊天。
- 工作区运行中复用本地归档 Agent run 的资料读取与工具输入/输出步骤，支持原折叠与动态效果；完成后保留原结果页，按任务使用指标、报价明细、清单、时间表和比较等形式。主结果优先，过程摘要按需展开；不用大量卡片嵌套或重复标题。结果格式可扩展，但不得直接执行模型输出的HTML或脚本。
- AI上下文栏与聊天工具栏之间使用1px主题边框色分隔，维持共享48px上下文栏高度，不叠加空白行。
- 业务确认面板展示具体操作与当前工作成果中的关键数据：预约区分租金、可退押金与支付合计，履约/协同呈现范围、负责人和时间。使用「返回核对」与具体确认动作；演示限制放在底部辅助区，不用通用提示段落代替业务核对。面板圆角跟随容器token，保留原Dialog开关动效与动态偏好。
- 当前为前端演示：示例、未连接模型与业务数据的限制必须常显；演示进度、附件、确认回执不能冒充真实读取、上传或业务执行。自动化配置只在当前会话保留，不能暗示已启用后台调度。
- 组件来源、能力清单与接入边界见[AI运营官说明](../../../apps/admin/src/features/ai-operator/README.md)。本地归档不是官方 Pro React 源码，来源、导入基线与接入改动随代码保存。

## 6. 表单、动作与反馈

### 6.1 表单与动作

字段必须有稳定标签；placeholder 仅作示例，不能代替标签。必填、单位、格式及限制在提交前明确，错误靠近字段并说明修正方法。保留已有 Form 值、空值、校验、禁用、ref 与未保存处理。

日期时间范围使用一体式 `DatePicker.RangePicker showTime`，保留 Dayjs、秒值、清空和原限制；不得拆成多个日期/时间/秒输入。金额不因换组件将未填写值改为零。富文本与上传沿公共安全编码、字符上限和真实文件结果。

允许单端为空的日期范围也只占一个筛选入口；端点编辑和快捷范围放入原UIArc锚定浮层，保留原回调及禁用条件。不得把两端表单直接撑入固定高度的筛选行。

表格选择列始终先于业务固定列。长表头在本列内省略并提供完整名称，不能换行撑高紧凑表头或覆盖相邻列。

| 动作 | 共享入口与约束 |
| --- | --- |
| 保存 | SaveButton；校验后等待真实 mutateAsync，保留原 payload 转换 |
| 执行、测试连接 | ActionButton；返回真实 Promise，失败须 reject |
| 删除、危险动作 | ConfirmAction；明确对象和后果，等待实际结果 |
| 导航、取消 | Button；不伪装成保存或执行成功 |
| 复制 | CopyButton；只在实际复制完成后反馈 |

提交中防重复、保留输入并显示真实状态。结果未知时按原操作核对，不盲目重发；没有真实撤销能力不显示 Undo。

### 6.2 加载与恢复

| 状态 | 呈现规则 |
| --- | --- |
| 页面、路由、会话等待 | 原 3×3 方格 LoadingState；不使用页面结构骨架 |
| 表格首次加载 | 仅数据区使用简化骨架；保留表头、筛选及列几何 |
| 表格刷新、筛选、排序 | 保留原行布局，表内显示加载；旧数据操作暂停 |
| 无记录 | 说明尚无业务记录，按权限提供创建入口 |
| 无匹配结果 | 提示调整或清除筛选 |
| 读取失败 | 明确失败；有真实读取能力时提供重试 |
| 无权限、不可用 | 明确限制，不伪装为空数据 |
| 成功 | 在原操作或所属区域简短确认，不强制弹窗 |

骨架只保留单行主要信息块，选择列和操作列留空；不绘制头像、第二行小字或完整页面轮廓。骨架几何由 `ADMIN_LOADING_METRICS` 维护，呼吸效果沿原 UIArc。

刷新时旧表体 inert 且不重复暴露给读屏。加载结束或失败必须退出等待；不添加模拟进度、假轮询或额外刷新状态横条。

字段错误就地显示，业务阻断常显，轻量消息使用 `useFeedback`。重要错误不能只靠短暂 Toast；同一错误不多处重复播报。现有 QueryState 尚未统一提供就地重试，具体页面需接真实恢复动作。

### 6.3 文案与本地化

使用租赁行业常用短语，动作说明结果，术语全站一致。英文按语境表达，不逐字翻译或靠加宽控件容纳长文案。

| 中文语境 | 英文 |
| --- | --- |
| 租赁交易 / 订单 | Rentals / Orders |
| 定价分组 / 资产与库存 | Rate groups / Assets & stock |
| 领取 / 归还；办理领取 / 归还 | Pickup / Return；Check out / Check in |
| 出库 / 入库；增值服务 | Dispatch / Receive；Add-ons |
| 续租 / 订阅续费 | Extend rental / Renew |
| 押金 / 预授权；待裁定费用 | Deposit / Preauth；Fee review |

完整消息通过 [locale.tsx](../../../apps/admin/src/app/locale.tsx)与变量翻译，正确处理复数、单位和顺序；不拼接中文碎片。客户姓名、商品名、历史备注等录入事实不自动翻译。费用、订阅和不可用后果不得为求简短而省略。

## 7. 表格与业务数据边界

### 7.1 统一入口与来源

普通列表从 `@/components/ui` 使用 `Table`，需要标题或筛选时组合 `ListSection`；多个快照子表可由 `TableRefreshProvider` 继承所属查询。不要复制订单页 CSS、另绘分页或给每页拼独立工具栏。

Table/AnimatedTable 共用 DataTable 渲染、分页、刷新、排序与列显隐。高级树、选择、筛选或自定义槽位暂不适配时，明确保留兼容实现，不丢失契约。

| 来源 | 职责与追溯 |
| --- | --- |
| Tablecn | 表格、菜单、状态标签外观；[固定源码与许可](../../../packages/ui-tablecn/README.md) |
| TanStack | 行列、受控排序、显隐、固定列与选择模型；版本看 package/lock |
| Motiq | 数据行与值变化动效；[保留源码、参数及许可](../../../packages/ui-motiq/README.md) |
| UIArc | 按钮、输入、选择、复选框、分页等基础控件；[适配说明](../../../packages/ui-arc/README.md) |

### 7.2 视觉、布局与字段呈现

- 只保留表格自身细边框和圆角；首尾列使用 space-4 边缘留白，表头文字与正文起点一致。
- 普通共享 Table 使用 36px 紧凑表头；底层 DataTable 的非紧凑默认表头为 40px。表头尺寸不等于工具栏或数据行高度。
- 单值单元格显式设整行垂直居中；多行格保持顶部主辅层级。首行区域由 `DataTableLeading` 统一为 32px，不设固定数据行高或裁掉必要说明。
- 每行保留一个主要识别值。次要资料降级，重复身份、品类方块及无实际图片的数据装饰不展示。
- 空表只显示一个紧凑占位，不显示零条分页。占位以表格当前可视区域居中，横向滚动后仍可见，不按隐藏列总宽度居中。非空列表保留统一条数选择器。
- 资料详情内的单表名称、新增动作与刷新/排序/列显隐共用工具行；纯说明不另占一行推远表格。录入区保留与填写相关的约束，资金、权限与风险说明不得删去。
- 金额使用 `DataTableMoney`；数字/负号 16px/600，币种 12px/400，同基线。只拆视觉权重，不重算金额、精度或币种；真实零与缺失明确区分。
- 状态使用语义图标与文字。订单主生命周期显式用 soft 标签，辅助分配/费用使用 `DataTableNote`；其他业务不照搬订单状态机。
- 操作列采用“状态主操作＋三点菜单”。主操作保留图标与文字，菜单不重复主操作；空菜单禁用，不做悬停展开。
- 订单和普通共享表格的动作列共用 `ADMIN_TABLE_COLUMN_WIDTH.actions`（当前208px）。页面不得为同一种动作组合复制宽度；有明确业务需要的复杂表格可显式指定列宽。禁用、处理中及权限条件在主操作和菜单中同样有效，不能因收纳动作丢失。
- 操作列默认固定在右侧，普通及兼容表格共用此约定。窄屏仍保留操作入口；左侧识别列可随表滚动，避免两侧固定列挤满视口。仅特殊业务布局可显式覆盖固定位置，不按页面遗漏配置。固定列使用不透明主题表面与细分隔，横向滚动不透出底下内容。
- 日期保留业务所需完整年月日与时间。紧凑时长最多显示两个主要单位，完整精度保留在可访问说明中，不改变费用或超时判据。
- 订单商品默认显示首项与数量，剩余项主动展开；展开状态按稳定行 ID 维护，不因时钟、排序或普通刷新丢失。

### 7.4 数据、刷新、分页与选择

- 服务端分页场景必须由服务端先筛选、排序再分页。没有真实排序支持时禁用相应入口并说明原因，不能仅排序当前页冒充全量。
- 本地完整 dataSource 可先排序再分页；远程返回的一页不得再当全量过滤或重复截取。
- 刷新绑定所属表格的真实只读查询，不刷新浏览器、不重发业务写入。无读取来源的本地预览禁用刷新；多张表的查询、筛选和展开上下文不得串用。
- 普通分页默认 20 条，保留既有明确初始值；显示 10/20/50/100 条数入口，条数变化回第一页。明确 pagination=false 或 showSizeChanger=false 的特殊预览保留契约。
- 条数选择器按内容定宽，选项单行、无勾选占位；当前值在触发框显示。此规则只作用于分页条数，不改变其他 Select。
- 表头全选仅覆盖当前页；跨页选择摘要区分全部已选与当前页已选。身份、租户、空间变化清空选择；旧结果占位、读取中或失败时不新增选择。
- 选择缓存不是授权，不默认选择未加载的全部结果，也不自动提供批量动作。
- 单元格动效必须显式配置稳定 `meta.motion.value`。语言、勾选、时钟或 React 节点变化不算业务数据变化；未知金额不能补零参与插值。
- 历史名称、规则和价格读取原关联快照，不用实时主档替代；日期与时区沿业务契约，不能将当前库存快照解释为期间利用率。
- 列表快捷导航只定位已有详情操作，进入详情后重新核对状态与权限；不能自动提交、抢锁或显示成功。

### 7.5 新页面接入

1. 确认任务是否需要表格；少量独立对象、设置与摘要可选清单或表单。
2. 定义自己的字段层级、稳定行 ID、权限和可隐藏信息。
3. 接原查询、分页与排序，提供真实刷新；使用 ListSection/toolbar 组织筛选。
4. 按需接选择、整格对齐及数据动效，保留金额、快照与 scope 边界。
5. 检查加载、空态、失败、无权限、长文本、窄屏、深浅色和双语。

### 7.6 搜索与筛选

- 会员、目录、账号等持续增长的管理列表必须支持查找。采用一个综合搜索，配业务必需条件；只有两三个条件且空间充足时直接显示，不机械收起，也不为填满一行增加条件。
- **视图导航与查询分类分开使用。** `Tabs` 切换独立内容、字段结构或表单，放在查询栏上方，窄屏通过原轨道横向滚动保持可达，不收进“更多搜索”。资产/数量库存、业务规则/日历/通知、支付/短信/云存储均属视图导航；没有自带面板也不改变其导航用途。
- 同一列表按状态、进度或版本筛选，使用 `Segmented`，顺序统一为**分类 → 综合搜索 → 常用条件 → 更多搜索 → 表格工具**。例如订单分配进度、租户状态和订阅版本属于查询条件；订单日期范围优先显示。切换了表头、数据结构或编辑任务时，不因外观相似就当作搜索分类。
- 导航与分段筛选的文字状态共享 `ADMIN_CHOICE_STYLE`：未选中为 `text-muted`，选中、悬停与按下为 `foreground`，字重固定 500；不使用品牌蓝字表示选中，不随状态改变字重。浅深主题随语义色更新，图标继承标签颜色；禁用、焦点和原滑块/面板动效沿组件实现保留。兼容分支使用同一文字规则，页面不另设颜色。
- 综合搜索只覆盖当前任务相关字段，例如会员姓名、邮箱、手机尾号，或目录名称、编码。标签必须准确说明支持范围；未授权的明文资料不参与搜索，也不得为搜索额外返回敏感字段。
- 搜索栏按实际可用宽度计算，默认只占一行。能放下的条件展开；变窄时从后往前逐个收起，变宽时按原顺序恢复，不预留空槽。综合搜索优先保留，订单日期优先于其他条件；极窄时分类也可进入浮层，工具文字可退为有可访问名称的图标。
- “更多搜索”使用按钮下方、起始边对齐的小浮层，宽度读取 `ADMIN_LIST_METRICS.filterPopoverWidth`（当前 320px），靠近视口边缘自动避让。字段竖排，使用现有标签、8px 控件间距与 12px 字段组间距；不使用大弹窗、遮罩或重复说明。
- 浮层按钮显示已选隐藏条件数量。收起、展开和响应式迁移不得清空条件或额外发业务写请求；选择后保留原生效时机，清除复用原逻辑。支持 Esc、点击外部关闭及焦点返回，子级选择器和日历保持原组件及动效。
- 常规可清除日期范围与单选条件有值时在框内显示 ×，同一位置不再叠加下拉箭头；空值时恢复箭头。不另起一行放字段级“清空”按钮，清除仅影响该字段，并保留原回调与焦点。
- 完整授权数组复用 `ListFilters` 与 `useListFilter`，支持忽略大小写、全半角及多词匹配；关键词、状态或条数变化回第一页，清除后恢复原列表。各列表独立维护条件和页码。
- 服务端分页必须把关键词送入真实接口，查询与总数采用同一条件后再分页；回车查询应在输入提示中说明。禁止只搜索已返回的一页并冒充全量结果。
- 页面通过 `ListSection.controls` 或 `Table.toolbar` 提供条件，由共享 `ListFilterBar` 排列；自定义组合条件用 `ListFilterItem` 描述标签、已选状态、宽度角色及优先级。尺寸、收起规则、浮层和工具统一维护，不在页面另写宽高或复制响应式逻辑。
- 工具栏、独立筛选行与筛选浮层均绑定列表宽度角色，不能意外继承表单的全宽规格。工具行容器不宽于960px时，导入/导出、排序及列设置优先收为图标，保留名称与悬停说明，为搜索和必要日期留出空间。
- 导航优先放在列表或表单上方；共享工具栏也会将误传入条件插槽的 `Tabs` 独立渲染，防止它被计入隐藏条件和已选数量。分区与工具栏之间仍只由共享 8px gap 管理。
- 固定少量配置、表单、详情子表与有数量上限的近期快照不机械增加搜索；近期快照要支持全量查找时，先补服务端查询与总数契约。

### 7.7 导入与导出

- 页面按业务用途声明能力，禁止给所有表格机械添加按钮。使用共享 Table 的 exportConfig / importConfig；独立服务端表格复用同一工具组件。
- 导出仅映射显式声明的公开字段，不展开原始对象、证据、凭据或未解密字段。完整本地数据导出当前筛选结果；服务端分页明确标为“导出本页”，不得把一页冒充全部结果。勾选后可单独导出所选。
- 资料导入使用 UTF-8 CSV，必须提供空白模板、字段说明、上传校验、逐行预览及结果下载。单批最多 500 条、2MB。对账保留其独立的 10MB / 10,000 行正式协议，不套资料导入限制。
- 本期导入只新增，重复记录跳过；文件不能携带内部 ID、更改状态、密码、余额、权限或自动审批。预览不写入，确认前重新查重。脱敏资料的查重由服务端完成，不为查重解密手机号。
- 任一写入结果不明立即停止后续项，区分已完成、重复、失败、结果待核实和未执行；禁止自动重试、补写或用成功提示覆盖失败。更换账号、租户或经营空间后清理文件与选择状态。
- 模板不是任意业务写入入口：套装组成、价格发布、资金、库存数量调整和资格审核继续使用原流程；不通过 CSV 代替审核或账务操作。

### 7.8 列表与卡片视图

- 只有需要浏览、比较或依赖图片/权益摘要的对象提供卡片视图。流水、账务、审核、审计和复杂配置矩阵默认保留列表。
- 切换控件固定为工具栏最右侧的图标分段控件，使用共享 Segmented 的 iconOnly 模式；两项共用底座和原选中滑块，保持 36px 外高，不使用两个分离按钮。
- 图标在按钮与选中底座中水平、垂直居中；只适配外壳布局，不修改 vendor 滑动动画。列表、卡片两个图标均有可访问名称，支持键盘方向键。
- 两种视图共用同一数据源、搜索、排序、分页和勾选状态，切换不重新取另一套数据。刷新期间保持所选视图。卡片不受列表列显隐控制，卡片模式隐藏列显隐工具。
- 卡片突出名称、状态及关键业务信息，编码和版本作为辅助；保留原操作权限。列数依容器宽度响应，最小宽度来自 ADMIN_LIST_CAPABILITY_METRICS，窄屏单列，不在页面写私有尺寸。
- 资产卡以资产编号识别实物，显示型号、地点和状态；图片复用所属型号的标准图，不冒充实物照片。数量库存卡突出服务端可用量，并同时保留在手、预占、维护及异常原因；不在前端推算库存。地点卡展示地点类型、履约能力、经营主体和营业时间，联系方式进入只读详情。
- 浏览卡片直接使用原 UIArc Card。保留原内容内边距（20px）、标题（18px）和展开/返回动效；不添加营销式大头图色块、装饰大图标或固定卡片高度。网格最小宽度统一为240px，实际宽度随容器分配；内容高度由必要信息决定。
- 收起时只展示名称、短状态和两三项核心事实。会员方案保留等级、推荐/默认、主要权益；器材保留图片、库存方式和简短规格；分组、优惠、服务突出实际价格或减免及适用条件。编码/版本放在原 Card footer；完整规格、权益、保障与叠加规则进入详情。不虚构收费、会员数，也不把尚未生效的配置展示为已可用权益。
- 有图时，图片直接铺满 Card media 顶部，四边不加内衬。共享 mediaHeight 为120px，使用 object-fit: cover、居中按比例裁切，禁止拉伸。无图片时不显示占据上半卡片的占位色块；加载失败保留明确的不可用状态。
- 点击卡片先查看只读详情：桌面使用 Card 原生 quick look，窄屏使用原 Bottom sheet。编辑、发布、历史、押金/预授权和容量等入口在详情中调用原流程；等预览实际退出后再打开后续操作，禁止两个浮层同时争抢焦点。
- 勾选与预览独立；点击勾选框不得打开详情。预览期间隐藏多选浮栏。记录、租户、空间或用户变化时，清理旧预览及待执行的后续操作；不复用跨身份的动作。
- 卡片内查看详情与预览操作直接使用原UIArc Button的variant/size；不叠加Ant样式或兼容层外观。多选直接使用原UIArc Checkbox，保持18px可见方框与原点击区域、键盘和勾选动效；统一放在名称右侧，与标题首行居中，不叠在图片上，不增加胶囊、白底或装饰容器。复选框随原卡片移动，预览中不重复显示。
- 会员方案以等级、主权益和最多两项补充权益形成层次；推荐使用轻微警示色语义强调，默认方案作为辅助标记。不虚构会费、会员数，未生效权益明确标注。器材按厂商、型号等有效字段分组，不用空横杠填满详情；定价分组展示实际单价和包含型号，优惠展示门槛及适用范围，保障服务展示实际额度与免赔额。正文中的金额或主权益使用 foundation text-2xl，辅助事实使用共享正文/次要字级；不增加固定高度。
- quick look 保留原圆角、遮罩及展开/返回动效。外壳裁切，内容区独立滚动；细滚动条使用主题边框色，不得越出圆角外壳、覆盖图片或挤出额外白色轨道。关闭按钮始终可见；关闭后恢复原卡片与焦点。样式只作用于业务卡片预览，不修改 vendor 或其他弹窗。

### 7.9 多选与批量操作

- 提供导出或合法批量动作的列表才显示勾选框。选中后显示一个浮动操作栏，包含数量、选择当前页、适用动作和清除入口；无选择不占位。多表页面一次仅显示当前选择栏。
- “选择当前页”仅覆盖已加载且可选择的行，不暗示选中未知全量数据。完整本地列表允许跨本地分页保留选择；筛选掉的记录清理。订单服务端分页切换页码或条件时清理选择。
- 动作由业务页显式提供，逐行校验资格，并在请求前重新读取当前事实和权限。只调用原业务命令，不从前端直接删记录、批量改账或统一改履约状态。
- 破坏性动作确认后执行；原流程要求原因时必须填写。展示符合条件数量、真实结果与未执行项，支持下载结果。部分成功不宣称全部成功，也不伪造事务回滚或撤销。
- 浮栏使用主题浮层、阴影、圆角与控件 token，保持窄屏可操作和安全区距离；为底部分页保留可滚动空间，不遮挡最后一行或分页器。

### 7.10 图标统一

- 常规工具保留 Lucide；导航与页头统一采用 Animate UI 原版 Hugeicons，缺少同形版本时选同系列的明确语义图形。概览与报表分别使用 LayoutDashboard、ChartColumn，不复用同一符号。兼容旧名字的入口为 components/ui/icons.tsx，业务页不再直接引入 Ant 常规图标。
- 工具图标默认16px、描边1.75；页头22px、导航18px，由 ADMIN_ICON_METRICS 与 ADMIN_SIDEBAR_METRICS 管理。使用按需 SVG 导入，不使用图标字体。
- 品牌标志保留各品牌原标志，不以通用图标伪造。图标按钮必须有名称，装饰性 SVG 使用 aria-hidden，不能只靠图标表达高风险状态。
- 动态图标由共享 `AnimatedIcon` 适配；导航、导入/导出等在整个可点击区域悬停或聚焦时播放一次，刷新仅在原读取进行中循环。无空闲循环，无全页扫描或观察器；减少动态时静态显示。状态、风险和资金识别图标保持静态。不得为图标添加额外键盘焦点或更改按钮行为。
- Animate UI 原路径、变体及控制引擎按固定提交保存于 `components/ui/animated-icons`，来源、哈希、导入适配及许可随 `sources.json` 和 LICENSE.md 留存；不改写原动画来仿制效果，不安装整个图标目录。

### 7.11 姓名预览与补充信息展开

- 关联客户姓名、企业名统一通过 CustomerPreview 使用原 UIArc HoverCard 与 HoverCardProfile。保留原头像/姓名、身份说明、简介、摘要与底部辅助信息结构，仅替换业务内容；不重新拼装浮层样式。触发入口使用原Button与头像样式组成胶囊，过长名称省略，完整名称保持可访问。
- 姓名胶囊使用小号控件高度，左内边距为0；头像填满扣除外边框后的高度，取消头像自身的第二圈边框，仅保留胶囊轮廓。姓名间距与右内边距沿用原组件，不能在列表或详情单独补左侧留白。
- Hover card保留原26px面板圆角、阴影、16px内边距和动效。圆角来自共享原生组件token，局部声明在Portal面板上，避免被页面容器圆角覆盖。宽屏优先侧置、窄屏下置，位置和避让交给原组件。
- 头像无真实来源时使用原首字母/姓名字形回退，企业使用企业图形。简介放脱敏联系方式、地区或真实关联信息；摘要放已知会员状态和等级，缺失项省略；底部标明当前资料或原记录来源，有真实更新时间才显示时间。不伪造头像、订单数、消费额或余额来填满布局。
- 当前资料按客户ID读取，预览打开后才请求；同名客户不得混用。沿原客户详情GET权限与数据范围，缓存隔离租户、空间、用户、角色权限、组织及地点范围；只保留安全展示字段，不缓存明文联系方式、证件或完整客户对象。权限不足、失败和无主档ID时不扩大读取、不猜测匹配。
- 原订单/报表行继续展示原快照；预览中的当前资料不回写历史。预览只读，编辑/审核仍走已有入口。没有主档ID、只有姓名的联系人、系统操作员、通知模板和打印文档不强行套用客户预览。
- RecordDisclosure直接使用原UIArc ExpandableCard，保留原34px圆角及展开/收起动画，用于独立详情中的建档、追溯、冻结条款等低频信息。默认收起，只展开同一内容，不横向撑宽页面；不得把风险、应付、待办或必填字段藏入其中，也不在密集表格单元格或卡片网格里叠加展开容器。
- 交付时以真实登录后台检查入口、布局、定位和展开状态；示例页或静态检查不能替代实页验证。无对应业务记录的分支单独标记未完成真实数据验收，不为演示而创建或修改业务记录。

## 8. 动效与可访问性

### 8.1 动效归属

UIArc 控件使用原动效；共享宿主负责必要适配，不改 vendor 参数或给同一组件叠第二层同职责动画。尺寸与布局调整不得顺带重写 hover、press、滑块、抽屉或音效。

浮层沿现有 Portal 和宿主层级定位。先排查祖先 transform、overflow 与裁切，不通过不断增大 z-index 掩盖结构问题；抽屉内的选择、提示和焦点仍须可见。

重要内容变化须有连续反馈，避免整页刷新般的突变。侧栏、顶部栏和未变化区域保持稳定；同一区域只设一个动效负责人。主题切换仍由AppearanceProvider负责，原组件的hover、press、浮层、卡片和数据动效继续保留。

| 场景 | 归属与规则 |
| --- | --- |
| 左侧导航切页 | WorkspaceNavigation使用Animate UI stack：新页从内容区下方覆盖，旧页缩至0.94、淡至0.6，500ms；参数集中在ADMIN_NAVIGATION_MOTION |
| 详情、返回及普通路由入口 | WorkspaceRouteReady确认懒加载路由提交后，工作区短淡入；不播放侧栏层叠，不叠加PageEnter |
| 列表/卡片及加载、错误、就绪内容更换 | 共享ContentTransition使用Animate UI原fade token，200ms；起始透明度由ADMIN_CONTENT_MOTION统一维护，节点与业务状态保持稳定 |
| 页签切换 | 原UIArc面板负责原动效；内容位于页签外时，显式传transitionKey或由ContentTransition包裹内容，避免仅滑块移动、内容直接跳变 |
| 表格排序、分页、数据及展开明细 | 保留Motiq行/值变化；展开明细复用原fade token，不对查询、勾选或时钟变化伪造数据插值 |
| 多选浮栏 | 原Animate UI Slide，8px短位移加200ms淡入淡出；退出即禁用交互，完成后卸载 |
| 导入、批量确认等弹窗 | 沿原组件关闭生命周期退出，afterClose后才清理挂载与内容；不得用条件渲染提前截断退出动效 |

新增内容淡入读取统一动态偏好，减少动效时直接显示结果。层叠或父层淡入期间不重复播放子层同职责淡入。连续操作可以中断，以最新状态为准；不按输入字符、时钟或无关重渲染触发整块动画，不改变React key、不重挂表单、不复制业务树。动效不得延后请求或要求用户等待动画结束才能继续操作。

导航快照只覆盖正文，不对整个根页面截图。快速点击以最后有效菜单为准；Chrome捕获期间重定向到根节点的点击，仅可在当前可见、可用的侧栏菜单范围内交回原处理器。结束、中断、窗口缩放和减少动态均须释放点击锁定；侧栏重新展开后，应让当前选中项保持可见。

层叠切换使用浏览器快照，仅保留一个活跃页面，禁止为过渡同时挂载两份业务页。连续操作可中断，最后一次导航优先；相同目的页不播放。不支持View Transitions、减少动态、已有浮层或主题过渡时直接导航，不延长加载等待。实际参数与许可分别见[表格动效说明](../../../packages/ui-motiq/README.md)、[工作区说明](../../../apps/admin/src/components/workspace/README.md)。Animate UI保留版本为MIT＋Commons Clause，不标为无附加条件的纯MIT。

“外观与音效 → 界面动效”提供三档浏览器本地设置：**跟随系统**为默认，实时读取 `prefers-reduced-motion`；**完整动效**显式启用原动效；**减少动效**省略页面层叠、图标循环及组件位移动画，保留静态状态、加载标识和操作结果。立即生效、刷新保留，并同步同源标签页，不写入租户或账户配置；音效独立控制。

所有动效消费者复用 `motionPreferences` 与 `usePrefersReducedMotion`。原组件通过构建入口适配读取同一偏好，CSS 减少动态规则绑定根节点的有效偏好；保留 vendor 源码和原动画参数。原 Motion 导出不变，仅替换偏好 hook；原始 API、CSS、主题过渡和导航共用一份解析结果。完整/减少切换不得通过重挂业务页面实现，避免清空未保存表单。新代码不得另读系统媒体查询形成第二套优先级。

不以循环装饰、假进度或延迟导航制造等待。减少动效时直接导航，释放进行中的快照和 inert；切回完整动效无需刷新。全局音效沿用户偏好，关闭声音不影响理解操作结果。

### 8.2 可访问性验收目标

以 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)为验收基线；以下为重点要求，不替代完整标准，也不代表现有全站已认证。

| 项目 | 验收要求 |
| --- | --- |
| 对比度 | 普通文本至少 4.5:1；符合标准大字号定义的文本至少 3:1；识别控件/状态所必需的非文本视觉信息至少 3:1，按标准例外判断 |
| 键盘与焦点 | 操作可用键盘完成，焦点可见且不被完全遮挡；菜单/弹窗关闭后合理返回触发点 |
| 控件名称 | 图标按钮有可访问名称，标签、可见文字与实际结果一致；展开状态与受控区域建立关联 |
| 表单与反馈 | 错误与字段关联；状态更新可被辅助技术感知，不只依靠颜色、声音或瞬时动画 |
| 点击目标 | 默认至少 24×24 CSS px，或符合[标准间距/其他例外](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)；触屏高频动作建议更大交互区 |
| 缩放与重排 | 文字放大至 200% 不丢信息或功能；普通内容在 320 CSS px 宽度可重排，表格等必要二维区域可内部滚动 |
| 拖动与悬停 | 拖动功能保留无需拖动的可用方式；必要帮助可通过键盘和触屏访问，不只在 hover 出现 |

不得通过全局取消 focus 样式、隐藏关键文字或只留图标解决视觉问题。验收需覆盖 Portal、固定列、吸附操作区与真实错误态。
