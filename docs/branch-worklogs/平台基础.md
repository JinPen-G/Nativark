# foundation-platform 分支工作日志

更新时间：2026-06-09

## 分支目标

本分支只处理平台底座能力：登录会话、系统用户、角色权限、租户/RBAC、数据权限、审计日志、系统参数、数据字典、编号规则、租户初始化、通用安全基线和前端系统管理页面。

本轮未修改 PRD、原型和业务知识库文件；未开发工作台、分时租赁、企业端和用户 H5，仅保留后续接口边界。

## 需求依据

- 用户最新要求：继续完善每个平台都要有的基础功能，页面按原型、逻辑按 PRD，没有 PRD 的基础功能按原型。
- 用户 2026-06-09 要求：优先推进 PF-18 接口契约或 PF-22 搜索与筛选预设中当前分支更适合的一项。本分支目标是平台底座，选择 PF-18；PF-22 保持后续业务列表体验任务。
- 用户 2026-06-09 追加要求：基于 PF-18 提交 `2ac0a52` 继续推进 PF-22 搜索与筛选预设，优先通用 DTO、平台后端 API、Prisma/MySQL 持久化，并在前端至少接入 1-2 个核心列表页。
- 门市租赁 MVP 要求：先做营运端和平台底座，MySQL 真实落地，H5/企业端只预留接口。
- 既有文档：`docs/门店租赁开发任务.md`、`docs/技术开发指南.md`。

## 本轮已完成

- 新增平台治理共享 DTO：审计日志、数据字典、编号规则、租户初始化。
- 后端新增 `/platform/audit-logs`、`/platform/dictionaries`、`/platform/number-rules`、`/platform/tenant-bootstrap`。
- 内存模式可直接运行；MySQL 模式复用 `SystemParameterSet` 和 `OperationLog` 落库，不新增 schema。
- `seed.ts` 补充平台治理权限码、数据字典默认值和编号规则默认值。
- `ApiAuthGuard` 补平台治理接口权限控制。
- 营运端新增 `PlatformGovernanceView.vue`，包含日志审计、数据字典、编号规则、租户初始化四个页签。
- 前端路由、菜单、权限管理页补平台治理入口和权限分组。
- PF-18 第一版：新增 `apps/api/src/contracts/openapi-document.ts` 作为接口契约源，覆盖 95 个控制器操作、关键 DTO 名称、operationId 和权限扩展字段。
- 新增 `GET /api/openapi.json`，返回原始 OpenAPI 3.0.3 JSON；`RequestIdInterceptor` 对该端点跳过 `{ data, requestId }` 包装。
- 新增 `scripts/validate-api-contracts.cjs` 和根脚本 `npm run contract:validate`，校验控制器路由、OpenAPI paths、operationId、`x-requiredPermissions`、路径参数和 schema `$ref`。
- PF-22 第一版：新增 `PlatformFilterPreset`、`SavePlatformFilterPresetRequest` 等共享 DTO，支持 `store-rental.orders`、`store-rental.vehicles`、`store-rental.members`、`store-rental.corporates` 四类列表 scope。
- 后端新增 `/platform/filter-presets`、`/platform/filter-presets/:id/default`，支持列表、保存/覆盖、设为默认、删除；内存模式可运行，MySQL 模式落 `FilterPreset` 表，并写 `OperationLog` 审计。
- 新增 Prisma `FilterPreset` 模型和 migration `20260609000100_add_filter_presets`。
- 营运端订单列表和车辆列表已接入筛选预设：选择预设、保存视图、设默认、删除预设、默认视图自动应用。

## 通用租赁改造影响点

- 数据字典和编号规则不要绑定汽车字段，可作为摄影器材、露营器材等品类的通用配置中心复用。
- 编号规则中 `STORE_ORDER`、`CONTRACT`、`CUSTOMER` 可保留，`VEHICLE_LICENSE` 后续应改为 `ASSET_CERTIFICATE` 或品类可配置编号。
- 审计日志的 `targetType` 应逐步从 `vehicle/order/member` 扩展为 `asset/order/customer`，便于通用租赁平台复用。
- 租户初始化模板后续应拆成“平台通用模板 + 汽车租赁业务模板”，避免摄影/露营租赁继承车辆特化配置。
