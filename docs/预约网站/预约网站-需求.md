## 1. 目标与归属

面向租户客户提供公开浏览、认证、报价预约及本人订单服务，与平台营销官网职责分开。原详细业务和安全规则仍引用[平台需求](../管理后台/管理后台-需求.md)和[客户端共用需求](../客户端共用/客户端共用-需求.md)，不在Web端建立第二套会员、订单、计价、库存或资金事实。

新增[企业客户后台专项](../企业客户后台/企业客户后台-需求.md)独立交付企业管理Web端；现有租户网站只按ECP-08接入员工企业身份/审批/告知的最小交易消费者，不重建网站，不将原WEB任务整体完成度移入ECP。

## 2. 原规划范围

- WEB-00确认用户、域名/租户绑定、首发地区、SEO、登录/支付、配送及与小程序的关系。
- WEB-01～06分别承接独立工程、认证与公开目录、Core报价/幂等建单、本人订单/费用响应、外部服务、浏览器/隐私/安全与发布；原依赖及启动条件只在任务维护。
- 不支持跨租户商城、跨空间混单或客户端分配资产。品牌、已发布空间、协议/帮助及服务来自租户配置，客户会话不复用运营账号。
- 页面不能决定金额、资格、订单/支付终态；输入变更按Core重新报价，失应答按原操作读取，不换键重复收费。
- Web支付按浏览器渠道实现，不照搬微信JSAPI；共享客户/会员不自动开放跨空间经营数据。

## 3. 已有工程与未决范围

[平台营销网站](../../apps/website/README.md)不是预约站；[租户消费者网站](../../apps/tenant-website/README.md)是已有独立工程入口。原WEB规划与现有工程的需求版本/任务对应、未验行为和发布边界需核对，不凭名称移转任务或新建第三套网站。

首发决策仍按WEB-00；没有证据的审批、域名证书、供应商及生产放行不补默认。当前工程说明属于实现证据来源，不替代正式需求。

## 4. 验收边界

保留原CLIENT-CHANNEL/CONTRACT、客户端真库、ORDER-CHANGE/MP-R1及真实Provider/D-11前置；WEB-06仍须浏览器/移动端、隐私/性能/安全及PILOT授权。静态页面/配置解析/模拟订单不等于真实建单、支付或发布验收。本次不启动应用、不变更业务范围，不重新评分。
