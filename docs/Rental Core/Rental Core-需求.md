## 1. 目标与层级

Rental Core为摄影设备、露营装备、车辆载具、工程设备提供统一的商品、资产/数量库存、报价、订单、分配、领取、归还、检查、费用和结算内核。不同品类复用同一主流程，由正式配置、策略和capability表达差异，不复制品类专用状态机或资金账。

本目录维护原租赁业务闭环；[品类治理](品类治理/品类治理-需求.md)独立维护定义、不可变版本、政策、空间采用及动态品类，保留CAT-GOV编号；[平台Core接入](../平台底座/Core接入/平台Core接入-需求.md)负责平台与行业Core解耦，保留PCH编号。CRM/TMS不是Rental新枚举或租赁Hook。两项专项不自动成为原CLOSE业务修复的全量前置。

## 3. 原闭环余项要求

以下是原12项CLOSE的需求归纳，具体范围与完成标准以原任务原行和平台条款为准，不形成第二套任务或新增验收编号。

| 原任务 | 必须闭合的结果 |
| --- | --- |
| CLOSE-MONEY-VERIFY | 取消/核减后的真实到账、超收、原路及分笔/并发退款均能按原支付单验签核对、恢复和追溯；不把未知结果当失败重做 |
| CLOSE-CORP-VERIFY | 企业债权、总回款payment、逐单核销payment_allocation不重复计收入；取消费、超授信最终债务、FIFO、历史无订单债权、重复/并发回款可核对 |
| CLOSE-USAGE | 报价冻结费率/包含量/阶梯/精度/封顶；按分配项读数及基线结算，补退经审核；读数修正有冲销/新裁定，分批/续租/换货不重复计费 |
| CLOSE-WAIVER | 冻结责任/排除条款、同一服务发生项累计额度及取消后的历史有效区间；事故时点有依据、责任可复核，旧上限缺失不补当前配置加收 |
| CLOSE-INSPECTION-VERIFY | 异常关联、事务内基线、事故/免赔、连续申诉与费用净额/裁定历史一致；客户响应有真实证据，不批量伪造确认 |
| CLOSE-NONRETURN | 丢失、盗损、拒还、承运丢件须有责任/证据、资源处置、应收/保证金、客户异议及补退闭环；不伪造归还或可租 |
| CLOSE-OFFRENT | 故障停租/维修换机按实际区间、责任和冻结规则裁定，租金/服务/运输分开，保留确认与争议 |
| CLOSE-VEHICLE-AFTER | 结算后违章/通行/后发现损坏、保证金保留/释放和通知申诉按适用法律及合同处理，不编通用保留天数 |
| CLOSE-GUARANTEE | 实付押金和真实外部预授权各自有创建/核验/抵扣/释放/过期/失败/对账与补偿，内部事件不是供应商冻结证据 |
| CLOSE-SAFETY | 证照、资格、资产检验/有效期、高风险检查按适用法规与已发布规则执行，可选开关不能绕强制条件 |
| CLOSE-NOTICE-VERIFY | 失败重试、补录、冷启动、多实例、关闭和生产模拟禁止可验证；通知受理不等于送达/已读，爽约宽限按原可信时点 |
| CLOSE-QUARANTINE-VERIFY | 分批/混合库存/多预占/同资源多异常按原分配项隔离；无法定位则保守隔离本批，不能跳过缓冲与高风险限制 |

## 4. 不可替代的边界

1. 当前Auth/Guard/ALS、audience及成员/资源范围由服务端可信来源决定；输入ID、AI建议、页面上下文和缓存不授予权限。
2. 历史依据、当前授权、新商业准入按平台§1.4逐动作组合：有效报价建单用原快照，新增时段独立续租按申请时适用价，全租期旧价补差用原依据，换货按明确选定基准；不能一概旧价或现价。
3. 正差额、负差额裁定与实际收退款分开；实收、核销、保证金、租金和服务不可混算。币种、精度与税口径沿用业务原工具/合同。
4. 订单、资源、服务容量、债权、资金事件和审计有明确事务所有者及锁顺序；外部支付不假定同事务。unknown、TTL、断线和取消请求不证明未提交/可重发。
5. 没有历史快照明确缺失，没有真实支付明确未核验；不得补零、当前默认或模拟成功作为正式事实。
6. 法律强制、租户合同与商户政策分开；地区规则映射/法律审查未验时不跨司法辖区推广。未决参数仍见平台§7.2，不由开发者编造。

## 5. 验收与交付

- 原12项逐项按任务原门槛核对；“待验收”不是已实现齐全，分别登记缺实现、缺装配/可信依赖、已知缺陷、缺真实证据。
- 每项覆盖正常、失败/重试、重复、并发和适用客户争议；人工节点有真实入口、阻断和审计，不靠改库收尾。
- 使用少量完整代表链，覆盖四品类适用组合及序列化/数量/套装、分批、历史变更；不以一张成功订单证明全部业务。
- 类型、静态、离线行为、真库、浏览器/微信宿主、真实供应商和生产放行分开记录。有限验证不降低原门槛，也不授权本轮连库/发布。
- 交付应可沿入口→服务→仓储/适配→共享合同→消费者找到正式接点；实现与恢复说明放任务，阶段证据放记录，当前归属/下一缺口放接续，不另建第五册。
