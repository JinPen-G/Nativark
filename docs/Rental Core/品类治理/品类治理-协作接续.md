## 5. 接手定位与核对顺序

### 5.1 先辨层级与版本

- 新增服装等租赁类型：本专项，仍使用Rental订单/库存/履约。

- 品类正文发布不改空间；政策修订不改正文；空间采用不改Core实现；程序回退不等于采用旧品类或恢复数据库。
- 原[项目指南§5.1](../../公共技术资料/开发指南/项目-开发指南.md#51-品类与动态字段)仍描述固定注册/迁移路径；本需求§1.4已明确动态组合能力完成后的目标替代。不能照旧指南给第五品类验收临时补枚举，也不能因目标已写就宣称当前动态创建可用。
