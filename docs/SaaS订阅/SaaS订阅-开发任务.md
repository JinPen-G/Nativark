## 2. 已确认的开发边界

1. 基础版、PRO 均按年收费；一个租户采用一个当前套餐和统一到期日，不另设 PRO 到期日。
2. 版本覆盖租户全部适用经营空间；PRO 包含各品类已发布的专业软件功能，外部服务、硬件另计，容量额度另定。
3. 首期标准套餐价、线下转账；现有 SaaS 管理员核实到账并直接开通、选择版本和设置有效期，不拆客服 / 财务 / 开通角色，不做报价接受和多级审批。
4. 保留租户升级 / 续费申请入口，但管理员直接开通不要求先有申请；租户不能自行修改版本、期限或授权。
5. PRO 功能既可公共下放基础版，也可只给指定租户额外授权；两种方式均不改变该租户的版本与统一有效期。
6. 功能可用范围按当前套餐公共权益与租户额外授权的并集判定，再校验有效期、交付状态、品类、空间配置、人员权限和业务条件；不把专业功能硬编码为仅 PRO。
7. 两个版本在租户管理后台左下角小浮窗提醒临近到期和已到期，可关闭、去重；续费或临时延长后撤下或更新旧提示。
8. 到期停止新业务，既有订单履约、归还、退款、退押、证据和争议保留；特殊情况管理员填写原因并临时延长，不设自动宽限。
9. 四品类各交付一个首批专业业务包，全部通过后正式销售 PRO；订阅页面或单一品类模块完成不等于销售放行。
10. 不重做租赁订单 / 资金内核，不把基础闭环缺陷转为 PRO 收费，不自动扣费、退款、删数据或解除安全冻结。
11. 租户员工 / 管理员小程序纳入本期框架：同一版本 / 权益、只读查看、菜单和页面访问控制、手机提醒及授权刷新；客户端预约小程序不展示商户内部订阅，移动端不提供套餐 / 期限修改。

本专项的四品类 PRO 销售计划与既有基础租赁试点顺序分别维护；不把本期订阅开发理解为同时启动全部品类储备功能。
