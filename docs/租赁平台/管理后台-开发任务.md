## 2. 原管理后台依赖顺序

1. 继续收口 `ACCESS-DATA-01` 与 `BILL-USAGE-01`：补全数据范围读写/导出矩阵、真库双账号验收，以及使用量阶梯管理端配置与历史快照。非金额会员权益另由 `BENEFIT-01` 决策和实现。
2. `SHARED-LOG-01A`，先补所有客户端共同依赖的本地配送规则；`SHIP-01` 单独验收，不能拿本地配送冒充承运寄送。
3. `ORDER-CHANGE-01`，关闭已有订单变更的后台和客户端出口。
4. `PILOT-01` 与客户端真实 Provider 验收并行推进。
5. `CAM-SUBTYPE-01` 验收摄影首单，再根据试点选择 `CAMP-01`、`VEH-01` 或 `CON-01`；不并行铺开三个品类。
6. `CORP-SETTLE-01`、`DOC-PRINT-01` 根据首个试点是否需要企业账期和正式凭证决定先后。
