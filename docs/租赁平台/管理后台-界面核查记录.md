## 交互复核结果

- 960px窗口35页无文档级横向溢出；24张带固定操作列的表格中23张有实际横向滚动距离，滚动前后操作列表头的横坐标差均小于1px。另1张表无需横向滚动。
- 七种卡片及只读预览已打开；检查图片铺满、名称旁选择、弹层边界与内部滚动。390px订单筛选及器材卡片BottomSheet也已打开查看；BottomSheet的屏幕外延伸是原组件拖拽结构，不作为内容滚动条越界处理。
- 订单更多搜索、客户HoverCard、多选浮条与清除选择已操作；没有执行任何批量业务变更。会员方案的列表与卡片两种视图均实际切换。
- 快速导航实测发现Chrome快照捕获期间将侧栏点击重定向到HTML，后续菜单点击丢失。取消根快照，并仅在捕获期间把主键点击交回当前可见侧栏菜单的原处理器；不直接拼路由、不扩大权限。四个菜单约80ms间隔连续点击后停在最后目标，`inert`及导航标记均清空。
- 减少动态模式直接导航；动画中缩放窗口仍到达已选目标并解除锁定。保留500ms层叠参数和原曲线，未为表单或内容Tab增加页面切换动效。
- 窗口从图标侧栏恢复完整侧栏后，等待原Menu挂载选中项再滚入视野；实测会员方案选中项位于导航可视区域内，不再因展开时机丢在屏幕外。
