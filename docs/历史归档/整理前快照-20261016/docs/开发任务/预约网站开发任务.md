## 1. 当前状态

状态：`Reserved`。

现有 `apps/website` 是 Rental OS 企业官网，不是租户面向客户的租赁预约站。预约网站尚未建立正式需求、工程和发布计划；不得直接把官网、运营管理端或小程序页面改造成预约网站。

## 3. 产品边界

- 预约网站与小程序共享租户会员、客户端 API、渠道配置、订单和资金事实。
- 不支持跨租户商城、跨空间混单或客户端直接分配资产。
- Web 支付能力按浏览器渠道单独实现，不照搬微信小程序 JSAPI。
- `apps/website` 保持企业官网职责；若启动预约网站，使用独立应用目录和发布配置。
