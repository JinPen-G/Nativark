## 1. 边界

本文件只记录多个客户自助端共用的能力。页面和宿主专属交互分别进入小程序、预约网站和 APP 分册。所有客户端必须复用同一套会员、目录、报价、订单、资金、文件和渠道配置事实，不得复制业务内核。

## 3. 外部前置

| 前置 | 需要提供的内容 | 未提供时允许完成到哪里 |
| --- | --- | --- |
| 微信小程序 | AppID、AppSecret、微信支付商户号、证书、合法域名和回调地址 | 代码、替身测试和专用库验证；不能完成真机或真实付款验收。 |
| 支付宝 | 应用、商户密钥/证书、沙箱或受控测试账号、回调地址 | 签名和适配器测试；不能标记真实收退款完成。 |
| 短信 | 阿里云或腾讯云账号、签名、模板编码和测试号码 | 配置与模拟响应；不能标记真实送达。 |
| 文件存储 | OSS、COS 或 S3 兼容桶、区域、密钥、CORS/回源配置 | 预签名和内存适配器测试；不能标记跨网络文件链完成。 |

## 4. 执行顺序

1. 先完成 `CLIENT-CHANNEL-01` 迁移和真库组合回归。
2. 再完成 `CLIENT-CONTRACT-01`，冻结小程序首期所需契约。
3. 有真实凭据后按文件 → 短信 → 支付的风险顺序完成 `EXT-03`、`EXT-02`、`EXT-01D`。
4. 最后执行 `CLIENT-ACCEPT-01`，作为小程序 MP-13/MP-14 和 PILOT-01 的共同前置。

## 5. 任务更新规则

- 本文件不记录某个页面的视觉、导航和宿主行为；这些进入对应端分册。
- “配置完整”“连通性测试通过”“真实业务交易通过”必须分开记录。
- 完成任务从本文件移除并进入[统一归档](../归档/多品类租赁平台已完成任务归档.md)。
