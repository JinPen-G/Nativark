# AIN-07-S03｜审批决定与提案修订 CAS

## 交付

- 新增 `ai-approval-repository.ts`：审批服务先要求外部当前授权返回 canonical actor/audience/scope，再校验 reviewed payload fingerprint；调用方不能自填审批人或 approvalId。
- Prisma 适配在 Serializable 事务中同时校验提案仍为待确认、当前版本 hash/期限有效，写入不可变 `ai_approvals`，再以 `stateRevision + status + currentRevision` CAS 将提案推进到 confirmed/cancelled。
- 同一主体同一 proposal revision 的同载荷同决定重放可返回既有审批；不同决定/载荷冲突。该切片不消费业务动作、不创建订单、不把 approval 当执行成功。

## 验证与未验

新增测试先验证 payload fingerprint 和缺失授权的拒绝边界；Prisma 真库并发、真实身份/权限、数据库提交应答丢失和 Core 业务幂等未在本切片执行。作者自测后待独立复核。
