# B13-W01～W06：三端真实订单页默认关闭入口装配

## 状态

已实现并待独立复核。本记录只覆盖本批真实页面入口准备，不代表 AI Native 已上线。

## 实现

- 管理端真实订单详情 `RentalOrderDetailPage` 导入 `AiTaskWorkbench`，使用明确的编译期默认关闭常量；页面上下文只读取既有 `id`、租户和当前空间投影，未提供读取器、动作回调或本地授权开关。
- 客户与员工订单详情页的实际 `index.json` 注册 workbench 和必要只读子组件，WXML 具名 slot 具备实际页面装配位置；`aiNativeEntryVisible` 默认 `false`，原订单页不创建 AI 组件树、不读取 AI 数据、不启动轮询。
- 两端页面补充 `onHide`/`onUnload` 清理入口；它们只调用已经存在的组件实例清理方法，不宣称可以撤销远端请求或权限。
- 保留既有 `AiTaskWorkbench` 的 host 注入边界；未接入正式服务能力时不提供 `attachHost`，没有空成功或本地审批。
