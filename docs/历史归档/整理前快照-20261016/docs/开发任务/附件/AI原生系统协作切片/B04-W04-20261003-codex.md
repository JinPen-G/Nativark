# B04-W04｜事件归并器

## 实现

新增 `event-reducer.ts` 作为无副作用纯归并器：

- cursor 仅按十进制字符串转 `BigInt` 比较，不转 JavaScript number；
- 重复 cursor 去重，倒序 cursor 拒绝；
- taskId/version 隔离，revision 倒退拒绝；
- `reset_required` 清空旧事件与续传 cursor，并标记需要重新核对。

归并器不承担身份授权、租户范围判断、服务端重放保护或业务状态写入。
