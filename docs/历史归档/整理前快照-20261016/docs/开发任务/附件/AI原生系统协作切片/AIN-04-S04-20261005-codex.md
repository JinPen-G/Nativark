## 已实现链

`服务端绑定 Profile + 当前 credential source → 实际 AuthService/ApiAuthGuard → PlatformModelConfigurationAuthority → AiScopeRepository 规范 PLATFORM owner → PrismaPlatformModelConnection → Profile/vault 同事务 CAS`。

消费侧独立链为 `既有 AiOrderRouteContextAuthority → 当前 workspace operator/staff user → 实际租户调用授权适配 → AiScopeRepository consumer/PLATFORM owner → 同一平台vault resolver`。管理与消费分别实例化 Scope adapter，不从caller flag临时切角色、不拼平台/空间 ID、不共用全局 mode。

- 新内部策略文件 `common/platform-ai-access-policy.ts` 只识别精确 `/platform/ai/providers/:profileId` 形状，GET要求 `system:ai-provider:view`，PUT要求 `system:ai-provider:manage`；其他方法/路径保持原默认拒绝。这里只是现有 Guard 的内部动作检查路径，不表示提供HTTP路由或冻结新的公共协议。
- 实际 Guard 将该明确能力列入 SaaS 域，但仍要求数据库当前权限显式包含该动作或显式 `*`；不把任一 SaaS 身份、租户管理权限当作默认授权。租户管理员，即使 isPlatformAdmin，也被身份门拒绝。保留平台AI命名空间中未定义路径/方法的专用拒绝，通配符和租户管理员特权也不能把未交付动作变为可用。没有新增自动角色grant或修改现有业务域权限。
- `PlatformModelConfigurationAuthority` 每次重新读取会话凭据并经过 Guard，校验当前SaaS身份/活动状态/ALS主体，构造已有正式平台上下文（顶层 permissions，没有伪造workspace/access字段）。Profile引用绑定构造时服务端选择的ID，不接受另一ID。当前失效、撤权、强制改密码和员工凭据拒绝。
- 调用授权复用已有 `TenantModelConfigurationAuthority` 和真实订单读取 authority；管理权限不替代订单/租户/空间调用权限，也不授予套餐权益、预算或dispatch权。
- `createAuthorizedPlatformModelConfiguration` 显式提供 management/invocation 两个resolver，验证实际Prisma必需方法和授权依赖；缺依赖fail closed，无自动注册AppModule/Controller、轮询、授权成功替身或供应商SDK。

## 装配合同与剩余

请求范围内调用 `createAuthorizedPlatformModelConfiguration({db,guard,credentials,invocation,profileId,secrets})`。guard必须现有真实 ApiAuthGuard，credentials必须服务器绑定当前会话来源，invocation必须真实受权资源入口（当前已实现订单读取），Profile是服务器选定且已持久化的规范PLATFORM配置，不来自Agent。管理入口使用 management.save；已授权workspace消费transport使用 invocation resolver。普通Agent仍不能选择model/URL/key。

没有提供正式HTTP入口、权限树/UI授权管理注册、首次平台Profile创建、生产根模块或部署。新增动作码需后续接 `PlatformService.permissionTree`（`platform.service.ts`，现有权限名称/seed来源）及受控角色配置流程；本轮不修改原权限seed，不给现有账号默认自动授权。现有显式权限存储/Guard能核验码，不等于所有SaaS账号已被授予能力。

能力专用验真与可信live记录、旧配置受权转换、多Profile、Gateway新预算单账及更广调用主体仍待推进。当前调用adapter只支持现有workspace operator/staff user；平台任务/client/automation不能因管理adapter完成而声称可派发。

真MySQL锁/并发/迁移、真实模型HTTP、浏览器/微信宿主/真机、部署未验。离线行为和显式组合不是生产启用；作者自查不是独立审查，原正式0/28保持。
