# B04-W01｜契约到展示模型的纯适配层

## 范围

新增 `apps/admin/src/features/ai-native/display-models.ts`，为任务、步骤、事件、Gateway 错误和用量提供纯转换函数。没有路由注册、API 请求、缓存、写入或副作用。

## 安全与状态口径

- 缺少 id、scope 无关但必要展示字段、未知状态或未知版本时输出 `unavailable/unknown`，不补造成功。
- `step.registered` 保留为 registered；事件 cursor 只接受字符串，禁止转成 JavaScript number。
- Gateway 错误不暴露原始错误、密钥、提示词或授权封套，前端错误默认不可自动重试。
- unknown 用量不显示金额或“免费”。输入对象不原地修改。
