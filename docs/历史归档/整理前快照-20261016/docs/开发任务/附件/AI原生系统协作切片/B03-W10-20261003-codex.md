# B03-W10｜能力探测与证据失效回归

## 认领与范围

- 本片在 `ai/ai-native-foundation-20261002` 当前 B03 基线施工。
- 仅补隔离离线回归与证据记录边界，不修改 Gateway、Router、Profile、Prisma、鉴权或中央文档。
- 目标是复用已有 `AiConnectionTestService`，核对每能力独立探测、unsupported/unverified 区分、凭据不进入请求、配置修订改变证据身份。

## 实现方式

- `tests/ai-native-b03-capability-probe-regression.test.cjs` 调用真实 `AiConnectionTestService.run`。
- Gateway 与 evidence 使用受控内存替身；网络拦截沿用既有 fixture。
- 合成 Gateway 返回只代表离线替身结果。测试只接受 `source=connection_test` 与 `details.result=synthetic_probe_only`，不把它升级为真实供应商可用性或 live 证据。
- 每个 capability 去重并单独记录；不支持能力标记 `unsupported`，传输失败标记 `unverified`。

## 验证

执行命令：

```text
node --test tests/ai-native-b03-capability-probe-regression.test.cjs
node node_modules/typescript/bin/tsc -p apps/api/tsconfig.json --noEmit --incremental false
git diff --check
```

证据等级：隔离类型/单元级函数回归；没有真库、真实 HTTP、浏览器/微信宿主、真实模型或外部供应商验证。

## 边界与后续

- 当前服务没有独立的 `probeMode=mock|live` 输入，也没有在本片新增该公共契约；因此本片只能证明合成结果被显式标记为 synthetic probe，不能证明真实连接测试已完成。
- 能力证据的持久化、配置修订失效和并发探测授权仍需真实 Prisma adapter、授权链和独立复核；不得以本片通过宣称生产闭环完成。
- 作者完成后待独立复核。
