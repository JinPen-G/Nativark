# B02-W10 知识文档与有界检索持久化

基线：`49f489e`。

## 实现

新增知识文档、版本、chunk、ACL、索引代次 Prisma 模型和 adapter。`KnowledgeService` 对创建、撤回和检索做 scope/数量/长度边界；撤回使用 revision 条件更新，active 检索不会读取 withdrawn 文档。检索仓储的查询同时绑定租户、空间、版本状态和 ACL read 权限，并设置 limit。
