# C02：AIN-11 预算核心依赖适配与故障验收

基线：`b5b2ebb2`。施工分支：`ai/ai-native-foundation-20261002`。

## 本批实现

- `budget-dependency-adapters.ts`
  - `ServerBudgetAuthorityAdapter` 同时要求服务端 context resolver、动作级授权器和正式 AI entitlement reader；缺任何一项即 `UNAVAILABLE`，不接受 caller scope 或 `entitled: true` 作为输入。
  - `SubscriptionBudgetEntitlementAdapter` 只消费正式订阅/功能目录快照，缺 `ai.native.use` 或平台 scope 无可用正式来源时拒绝/不可用，不推断 PRO 包含 AI。
  - `PersistedBudgetEvidenceAdapter` 只消费持久化 dispatch/usage reader，并逐项核对 reservation、call、actor、scope；证据引用字符串不能伪造 verified。
- `PrismaBudgetRepository`：
  - 幂等 fingerprint 补入 scene、model、actor、consumer scope、quantity、policy keys、config/price association 和过期时间；同键异载荷返回 `IDEMPOTENCY_CONFLICT`，同载荷从仓储恢复原记录。
  - ledger replay 比对 action、evidence hash、tokens/calls/money 数量和币种；不同事件载荷不得复用既有结果。
  - reservation 记录回传持久化 `actorId`，service 读取/结算时再次与当前授权主体核对。
  - 策略 `enabled` 由 gates、limited budget、allowlist、并发和单 run 上限计算；未配置/zero/停用仍拒绝，不会变成无限额度。
  - sceneCode 参与 consumer scope、policy rows、allowlist 和 reservation 校验，跨场景 policy row 被拒绝。
  - 活动 reservation/pending 只计并发；已结算 reservation 按实际 tokens/calls/money 进入后续预算聚合，实耗超过预留不会被截断或重新释放。
- 追加迁移 `20261004023000_ai_budget_ledger_replay_guard/migration.sql`：为 ledger 增加可保存 unknown 原因的 `reason` 字段；历史迁移未改写。当前构建使用尚未生成新字段的本地 Prisma client，因此业务代码暂不读取该列；交接整合时需隔离 generate 后再开启 reason 比对。
- `c02-dedicated-db-plan.cjs`：仅为未来明确授权的 `rental_os_e2e_*` 专库并发测试保留计划描述，默认拒绝执行，不读 `.env`、不连库。

## 主线接入合同与硬阻塞

主 Claude/Gateway 仍需提供：

1. 真实 request/job authority 的 `resolveContext + authorize(action, context, resource)`；不能以 caller scope 或常量 entitled 替代。
2. 订阅服务在独立事务中读取正式 AI feature catalog/grant，并把 `ai.native.use` 的 revision/available 传给 entitlement adapter；当前普通 `readCategoryCommercialContext` 只接受 Prisma transaction，不在本切片擅自注册调用。
3. 持久化 dispatch/usage reader 返回 reservation、call、actor、scope、dispatch 状态和不可伪造的 evidence hash。
4. Gateway 在 dispatch 前后接 reserve/dispatch/settle/reconcile，并保留 unknown；预算层不拥有供应商派发权。
5. Prisma client 重新隔离生成后核对追加 `reason` 字段与迁移；本批已在隔离生成 client 上接入 unknown reason 的 ledger replay 比对。

作者完成不等于 AIN-11 完成；C01/C02 仍待主线依赖适配、专用真库并发与最终 Gateway 集成验收。
