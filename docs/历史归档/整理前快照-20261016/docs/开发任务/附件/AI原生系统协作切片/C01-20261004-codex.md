  - `budget-settings.ts`、`budget-quantity.ts`：C07 设置校验、默认拒绝、tokens/calls/money 分单位和六位金额原子值。

  - `AiBudgetPolicy`：平台/租户/空间 scope、场景、修订、模型/场景白名单、预算单位、并发和单 run 上限。
  - `AiBudgetReservation`：request/run/step/action/call/idempotency、config revision、price version、scope、状态、dispatch state、unknown 保留。

- 金额不换汇、不猜价格，使用明确币种和六位小数；实际用量超预留不截断，保留真实入账路径。

## 主线接入合同

主 Claude/Gateway 需要提供并在真实授权链中接入：

1. `BudgetAuthority.resolve(action, resource)`：每个动作返回当前服务端 `AiExecutionContext`、动作授权 key、过期时间和权益判定；不得恒定 `authorized: true`。
2. `BudgetQuotePort.quote(command, grant)`：由可信报价/计量策略返回 canonical consumer scope、平台/租户/空间 policy keys、model、预留单位、`priceVersion`、证据 hash 和过期时间；不能接受客户端/模型费用上限。
3. `BudgetEvidencePort.dispatch/usage`：派发状态及真实 usage 证据；COMMIT 丢失或 usage unknown 必须进入 reconcile，不能自动 release/retry。
4. Gateway 在真正 dispatch 前后调用 budget reserve/dispatch/settle/reconcile，并在等待后重新授权、复核 config revision、scope、policy 和过期时间。
5. 组合根显式注入 Prisma repository 和以上适配器；当前没有自动注册或生产启用。
