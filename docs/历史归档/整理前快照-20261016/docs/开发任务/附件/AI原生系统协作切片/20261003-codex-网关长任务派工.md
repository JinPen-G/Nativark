- 双轨：新租户默认 `platform_managed`（Rental OS AI，无需Base URL/密钥/协议/模型）；已有自定义配置保留为 `tenant_managed`，切模式不能删除BYOK配置或密钥。

## 四、六个连续里程碑

### AIN-05/S02：双轨配置兼容 + Profile Router

- 保留旧TenantModelRecord读取，缺mode但已存在完整自定义配置按tenant_managed兼容；空租户默认platform_managed。**损坏/不完整旧配置不是新租户**，不得静默切平台发送数据。
- 保留BYOK设置与密钥，mode切换只改变来源选择。显式retain/replace/clear语义；更换协议/endpoint不能把旧密钥自动外发，配置revision冲突CAS拒绝。新租户无需创建key或填写模型才能选择Rental OS AI，但平台无可用配置时诚实unavailable，不报ready。
- Provider Router按当前主体scope、mode、scene、profile角色和能力要求选择route；允许多profile数据形状，不做复杂UI/智能成本路由。同一模式内没有合格route则明确拒绝，不跨mode/tenant兜底。
- 分开tenant consuming platform与SaaS platform task；模型配置属于平台不等于SaaS获得租户内容访问权。
- 配置仓储/审计/授权继续注入**必须端口**；不要自带allow-all或内存生产默认。缺端口启动/调用应fail-closed。DB adapter由Claude负责。
- 测试调用真实router/config方法，使用可控端口替身；涵盖新/旧/坏配置、切换保留、显式清钥、并发revision拒绝、两租户隔离、SaaS/客户/员工身份错配、无平台route。

### AIN-05/S03：能力证据与调用前拒绝

- 能力表覆盖text/streaming/tools/structured_output/image/audio/embedding/reasoning（只宣称真正支持的子集）。区分协议adapter实现能力、具体endpoint/model实际证据和运行所需能力；三者求交集。
- 证据关联config/profile/model/协议/修订/方法版本/时间；修改配置、rotate/clear key、换模型后旧证据失效。mock证据不得放行live路径；unsupported与未测分开。
- required能力缺失时在**取凭据、预算发起或请求dispatch之前**按合适顺序拒绝；optional不满足可不使用，但不能擅自删除任务required。
- 不用模型自报“我支持Tools”当探测证据。不能把健康文本pong覆盖为全部支持。
- 可控fixture模拟探测响应与时钟；测试配置修订、错主体、旧证据、部分能力、超时、取消、输入伪造能力等边界。未真实探测只写mock。

### AIN-05/S04：受控 HTTPS 出网 transport（离线测试，不实际联网）

- 实现实际可调用的server transport，但不注册为默认真实入口。注入resolver/请求创建器/clock便于离线检查真实构造的请求选项。
- 校验URL协议/用户名密码/fragment/query政策；校验**全部**DNS结果和IP归一化，拒绝回环、私网、link-local、metadata等受限地址。DNS返回空、非法family、mixed public/private、非有限/异常值fail-closed。
- pin被验证的目标IP用于连接，同时保持原hostname的Host/SNI/TLS证书校验；禁止二次不受控解析、关闭rejectUnauthorized、手工覆盖Host或继承环境代理绕过。
- 默认禁止redirect；30x不能转发密钥到别处。企业私网支持只能留显式受权部署政策端口，模型/租户字段无法打开；默认仍拒绝。
- timeout/deadline覆盖DNS/连接/headers/body；信号取消后释放资源；响应字节/请求体/headers边界，分块超限中止。不得只在全量body读完后检测。不自动重试已dispatch请求。
- 测试通过fake resolver/socket/request对象验证真实参数及资源清理，不启动本地server、不使用真实DNS/套接字。不能把fake网络测试称SSRF实网验收。

### AIN-05/S05：协议能力扩展、流解析与严格结果

- 基于ChatCompletionsAdapter扩展确实支持的tools/structured_output和stream能力；只处理服务端下发工具，不执行工具、不把模型输出当已提交业务结果。

- 不写死供应商或模型；endpoint由route传递，只读。实际协议不支持的字段/模式不能伪装通过或静默换协议重发。
- 增量流处理UTF-8跨块、CRLF/SSE边界、终止帧、tool argument碎片、重复/乱序/超限、结束但无明确finish、断线/取消。可观测partial不是完整成功，未知用量继续核对。

### AIN-05/S06：统一 Gateway + 连接测试应用服务

- 上层invoke/stream消费共享 `AiGatewayPortDraft`/Intent，消除调用者必填model的旧外部入口；旧低级generate如保留仅供内部adapter，不能成为绕过router的公开路径。

- 请求在flight后超时/失联→保守待核对，不能释放预算当免费失败重发；迟到结果最多一次结算；适配器忽略取消不能无限占槽或被盲目重复派发（清晰记录处理边界）。不擅自实现收费标准。

- 测试结果区分invalid/auth_failed/timeout/rate_limited/capability_not_supported/success；各能力单独显示mock/live/unverified证据。不在日志/结果/异常泄露key、完整厂商错误体或跨租户对象存在。
- Dynamic module要求必需端口，不接AppModule、Controller、Cron或真实供应商。HTTP/前端接线留给后续明确分工。
