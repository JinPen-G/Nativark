# B02-W04 Provider Router 路由边界

基线：`b741a53`。

## 实现

新增 `ProviderRouterService`。路由输入必须同时提供消费 scope、平台 scope、模式、场景和必需能力：`platform_managed` 只查询 `PLATFORM` scope，`tenant_managed` 只查询消费主体 scope。候选 profile 必须匹配 scope、模式、启用状态和未禁用状态；场景先选对应 role，再在同一 scope/模式内考虑 DEFAULT，不跨租户、跨空间或跨模式兜底。

所有候选都缺少必需能力时直接返回 `CAPABILITY_UNSUPPORTED`，不把另一个模式的 profile 当作隐式降级。
