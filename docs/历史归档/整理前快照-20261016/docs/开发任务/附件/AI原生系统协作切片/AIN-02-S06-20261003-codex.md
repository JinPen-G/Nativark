## 设计

按新决定，租户管理输入可配置协议、Base URL、模型、开关与secretChange（retain/replace/clear），expectedRevision必须显式提供。它是管理端写入专用DTO，不是C03模型输入；密钥writeOnly，不复用该schema作日志/响应。摘要只有配置版本、凭据状态与mock/live连接状态，无密钥。连接状态字段只是表达，不是本轮真连接证据。任意协议字符串不自动加载SDK/handler，运行期须解析到已注册的适配协议。

平台、租户、场景三级版本化开关不混同平台托管优先；平台仍可限额/停用。tenant scope与服务端C03配置引用、场景/模型allowlist分别存在，租户自配不能自签调用授权。所有引用只引用记录，关联scope/tenant/configRevision/credential归属仍需验证。

预算not_configured/zero/limited分开，无无限额分支或隐式默认；zero在TS/schema都要求字面零。token/call整数与money独立联合；金额6位定点十进制字符串、币种三位大写，无单价/汇率/订阅政策。precision选择是草案表示标准，不是收费标准，由协调者冻结。

预留为正数量，实际结算可零；reported/estimated/unknown复用C03类型，估算/未知保留reconcile，未知保留正预留而不是造零释放。release必须未发出或已验证未用，不能用unknown_usage作为释放原因。request/run/step/action/idempotencyKey、config/model/priceVersion与revision具备关联。applied/replayed/conflict(revision/payload)只是协议，未证明真实库去重/并发。
