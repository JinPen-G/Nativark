## 实际实现

内部流队列32事件或64KiB触发IncomingMessage.pause；同时降到8事件且16KiB以下才resume。仍保留256事件及原响应总字节硬上限，对忽略pause的peer不无界缓存；不改公网DNS校验、地址pin、TLS、禁重定向与原总deadline。

暂停期间取消、consumer return、超时均关闭本次request/response、清timer和队列，不resume已销毁资源。performPost失败同步通知stream内部错误状态，避免Promise.catch尚未运行时吐出超时后的缓存chunk。无公共端口改动，无HTTP/模型/数据库接线。
