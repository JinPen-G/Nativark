## 实现

- 在现有C04类型和S04事件表上实现内部 `AiTaskEventRepository.readPage`，输入只接受taskId/after/limit；拒绝scope、tenant、audience等自授字段和0/负数/过大分页。
- 复用实时授权及完整owner/scope查询，不复制权限规则。读取前与返回前都解析当前授权，即使空页/要求reset也重验；两次主体、scope、audience或automation政策变更则丢弃缓冲结果。
- `bindingKey`作为内部主体范围比对值由共同解析器生成，事务仓储改用同一个值，避免两条路径各维护一套比较。它不是授权token，不返回客户端。
- RepeatableRead有界只读事务内读任务版本和eventCursor，再按scope/task和after<cursor<=上界取limit+1条，固定快照上界避免新的事件混入旧任务版本。分页只回传实际最后事件游标，不直接跳到尚未读完的high-water。
- 游标用BigInt/字符串，不经过number；精确处理大于2^53的值及unsigned-bigint上限。拒绝未来游标、重复/乱序、跨scope/task记录、revision回退/越过任务快照、未知type或不合法payload。
- 显式解码4种C04事件，只提取声明data字段。内部initiator/audit封套不外传；业务输出仍只是resultId引用，需要后续另行授权读取。
- 无可用后续历史但task游标领先时返回cursor_expired/reset_required，不捏造事件；未知task协议返回unsupported_version/reset_required。合法游标空洞仍按C04允许，不把空洞简单当重复或过期。
