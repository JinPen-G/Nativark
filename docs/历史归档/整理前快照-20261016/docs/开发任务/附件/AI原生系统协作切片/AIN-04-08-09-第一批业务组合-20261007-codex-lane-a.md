## 可调用入口

- `tools.quote.businessPreparation.prepareUnified(input)`：返回缺项/歧义/可报价/不可用和下一步；不保存报价、不预占库存、不创建订单。
- `tools.quote.businessPreparation.inputSources(input)`：返回用户输入、用户选择、服务器上下文和 Core 规范化的来源分类；Core 规范化在正式报价前仍标记 `not_yet_called`。
- `tools.quote.businessPreparation.compareQuotes(previousQuote, currentQuote)`：只比较 Core 已返回字段，不重算金额；新报价禁止复用旧确认。
- `tools.quote.businessPreparation.commitHandoff()`：正式 order.commit 输入端口未向本线暴露，返回 `unavailable`。
- `tools.riskRecheck(input)`：单风险 reader 缺失时返回 `unavailable` 与精确缺口。

## 本批边界

- 订单事实已有历史报价/规则/检查模板的来源与缺失状态；支付/退款仅消费已加载的正式本地事实，未加载不解释为零或成功。
- 订单变更预览和正式建单仍由主线已有受权端口负责，本线不复制 Core 状态机、不写审批、不登记步骤。
- 计价金额由 Core 提供，AI 层不重算金额、优惠、押金或库存。
