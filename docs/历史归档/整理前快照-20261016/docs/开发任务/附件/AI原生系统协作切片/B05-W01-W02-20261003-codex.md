# B05-W01/W02｜组件维护性与 UIArc 适配

## W01

对 B04 一行式 feature 组件执行 Prettier 展开，拆出清晰的 props、派生状态和渲染分支；不改变原有状态语义。现有 B04 离线回归仍保持通过。

## W02

按钮、异步操作按钮、复选框和输入统一从 `@/components/ui` 引入；取消/恢复等返回 Promise 的命令使用 `ActionButton`，普通分页/查看操作使用 `Button`，复选框使用 `Checkbox`，字段输入使用 `Input`。没有修改 UIArc vendor。测试使用 feature-only UI adapter stub，生产路径仍解析真实 admin adapter。

验证：`node --test tests/ai-native-b05-ui-arc.test.cjs tests/ai-native-b04-*.cjs tests/ai-native-b04-*.mjs`；真实 React 静态渲染与既有离线逻辑回归通过，管理端严格类型检查通过。未验证浏览器点击、焦点、动画与真实异步失败视觉状态；作者完成后待独立复核。
