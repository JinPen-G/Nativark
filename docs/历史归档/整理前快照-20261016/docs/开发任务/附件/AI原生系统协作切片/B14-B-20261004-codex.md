# B14-B｜双轨 AI 设置前端准备（Codex，2026-10-04）

## 实现

- 新增 `ai-service-settings-model.ts`：消费现有 `AiTenantModelSettings*Draft`，把缺失摘要视为 `platform_managed`，保留既有 `tenant_managed` 的协议、HTTPS Base URL、模型标识；密钥只允许 retain/replace/clear 写意图，绝不从摘要读取或回显密钥。
- 新增 `AiServiceSettingsCard.tsx`：feature-local、无路由、无请求、无缓存。平台模式只显示 Rental OS AI 与 ready/unavailable/not_verified；BYOK 模式显示脱敏可编辑字段和明确密钥操作。保存由宿主显式注入，修订号由宿主提供。
- 现有平台系统参数页已有旧版平台级 AI 接入卡，但它不是租户双轨设置入口；本片不把它改成租户配置，也不创建第二个路由。新卡是可由未来租户设置宿主导入的装配件，不构成假保存入口。
- `SettingsSaveSession` 增加宿主上下文/修订/回调世代隔离、pending 防重、卸载后的迟到响应隔离和通用错误脱敏；请求返回只显示“请求已返回”，不宣称能力验证或业务生效。

## 阻塞与边界

服务端 AI 配置入口、权限、密钥托管和 revision 冲突处理不在本片范围；宿主未提供 `onSave` 时组件不会显示保存动作。普通租户平台模式不泄露平台供应商、模型、Base URL 或密钥。
