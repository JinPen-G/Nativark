生产确认按钮改用现有 `ActionButton` 的 `onAction: () => Promise<unknown>`，不再 `void` 丢弃 Promise。组件按 `proposalId:revision` 设置 React key，切换提案时旧按钮实例卸载；确认选择在首轮渲染检测到身份变化时立即清空，不等待 effect。新增 `SubmissionGate` 供可控 Promise 场景做单飞与迟到结果判定，拒绝身份不一致提交。
