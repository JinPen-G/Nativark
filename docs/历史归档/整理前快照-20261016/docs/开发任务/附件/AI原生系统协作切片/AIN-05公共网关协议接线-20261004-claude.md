## 实际接线

- `PublicAiGatewayService implements AiGatewayPortDraft`：公共invoke/stream消费完整AiExecutionContext和C03 Intent，依旧由真实routing解析当前身份，比较完整身份绑定；workspace operator/staff user以外的主体明确拒绝，不把platform/customer/automation伪装成workspace。
- 直接使用shared公共JSON Schema验证Intent、config、result和stream event，无额外字段/未知版本容忍。事件sequence从1开始；输出字数、usage范围、config标识沿用公共契约，不通过类型断言绕过。
- actual由本次真实路由的profile与owner构建，不从调用方取model/config、不填假凭据ref。mode/evidence由可信服务端runtime注册；verifyEvidence是必须的可信依赖、严格返回true；没有默认live成功验真器。
- invoke/stream复用已有UnifiedAiGatewayService的admission、dispatch唯一token、usage结算/unknown及路由复检；调用尝试拥有独立context与actual，未把请求状态放进服务单例字段。
- 已派发失败或ACCOUNTING_PENDING保守返回公共unknown、retryable=false、nextAction=reconcile。未能建立有效路由前的失败不伪造actual，抛安全错误；撤权后不再返回配置或结果。使用共享截止时间和有界cleanup，外层timeout不会被内层取消信号改写成CANCELLED。
- stream发started、text_delta、terminal；消费方在started后取消会关闭底层生命周期。每次恢复输出前重检，超长delta不作为非法公共事件发布；最终清理错误不覆盖已确定的公共结果，持久核对仍由内部生命周期保留。
- `RoutedModelTransport`按profile.protocol选择已注册ModelAdapter，不按供应商名猜模型、不跨owner回退。校验owner/profile/消费者、adapter能力、已选模型，然后从模式对应的可信resolver解析connection。
- connection绑定完整profile fingerprint、HTTPS baseUrl、credential及maxOutputTokens。调用前两次解析检查轮换，调用后及流片段前再次解析；超上限不传输。私钥不出现在返回值或原始异常中，跨流片段的credential前缀缓冲后确认安全才发布。
- `TenantModelConnectionResolver`实际调用现有TenantModelConfigService的selectionForInvocation/profile/credential，检查mode/configRevision/model/credentialRef一致并复检，使用现有SecretBox密文来源。平台resolver仍是显式可信依赖，没有假平台配置默认值。
- PublicAiGatewayModule提供register及registerProtocols，后者实际组合RoutedModelTransport和协议adapter；不会自动注册AppModule/Controller/Cron或启用生产。
