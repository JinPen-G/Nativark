# B04-W05/W06｜取消恢复与提案预览

`CancelRecoveryStatus` 仅消费宿主状态和显式回调，默认按钮禁用，不在挂载或事件到达时自动调用；取消请求、已取消、待核对恢复候选、未知结果分开显示。`ProposalPreview` 只展示宿主给出的标题、风险、有效期、依据和前后值，不重算金额、库存、资格或权限；缺依据不显示批准。

验证：`node --test tests/ai-native-b04-cancel-recovery.test.cjs tests/ai-native-b04-proposal-preview.test.cjs`，3 项真实 React 静态渲染通过。未验证浏览器交互、后端取消、恢复、审批消费或业务计算；作者完成后待独立复核。
