# B02-W09 受控连接测试与能力证据

基线：`19b8009`。

## 实现

新增 `AiConnectionTestService`。测试只接收统一 Gateway 的 invoke 端口，不读取 Base URL、API key 或供应商 SDK；每个能力使用唯一探针 callId，按结果写入 revision-bound connection_test 证据。能力不支持记为 unsupported，网络/供应商等其他失败记为 unverified，不把模拟成功当作真实模型连接证明。

## 验证

`node --test --test-concurrency=1 tests/ai-native-connection-test.test.cjs`：3/3 通过，网络拦截生效。

未调用真实模型、数据库或外部供应商；Gateway 实际 HTTP/Guard/预算和证据 adapter 的生产接线待组合验证。作者自查，待独立复核。
