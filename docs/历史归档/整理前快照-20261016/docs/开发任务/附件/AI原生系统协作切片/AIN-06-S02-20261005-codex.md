# AIN-06/S02：任务聚合结果提交适配端口（2026-10-05）

## 实现

运行器新增可选的 `AiTaskRunnerOutcomePort`。步骤结果仍先通过既有步骤仓储持久化；当组合根提供该端口时，运行器在返回 `succeeded`、`failed`、`paused` 或 `unknown` 前提交任务聚合状态，并要求端口返回更高的任务 revision 与最新 run fencing revision，随后用最新 fence 释放租约。端口异常、缺失有效 fence 或模糊提交结果均 fail-closed 为 `AI_STORAGE_UNAVAILABLE`，不把步骤成功冒充任务成功。

端口不实现状态机、不生成授权、不执行 Gateway/Core 动作；主线应把它接到已有 `AiTaskTransitionRepository`，由该仓储继续负责当前授权、状态转移规则、任务锁和事件事务。未提供端口时保留 C04 的低层步骤编排兼容性，但不宣称任务级终态已经持久化。

## 验证

- `tests/ai-native-c04-task-outcome-port.test.cjs`：覆盖终态提交先于最新 fence 释放、返回非法 fence 时拒绝成功。
- 使用运行器真实实现和受控内存端口；未连接真实数据库、未启动 worker/API、未验证 MySQL 锁或宕机恢复。
