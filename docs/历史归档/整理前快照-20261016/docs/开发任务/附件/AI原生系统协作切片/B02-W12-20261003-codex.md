# B02-W12 组合故障矩阵与显式接线清单

基线：`4de2452`。

## 实现

新增 `ai-native-composition.ts` 显式列出 Router、能力证据、admission、用量、Gateway、知识、记忆、人工确认、transport、audit 十个组件，并提供只读 wiring inspection/assertion。缺任意组件都会标记 `NOT_WIRED`，不会因为静态类型存在就误报平台 AI、数据库或供应商已可用。

组合故障覆盖：缺接线、预算组件缺失、审计缺失、transport 未启用。它与前面 W03/W05/W06/W07/W09/W10/W11 的失败语义保持分层，不把未知结果改成成功。
