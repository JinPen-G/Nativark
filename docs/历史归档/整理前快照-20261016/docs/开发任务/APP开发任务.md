## 3. 产品边界

- APP 复用客户端 v1、会员、订单、计价、支付和文件内核，不建立第二套业务事实。
- APP 的包名、签名、推送和支付凭证按渠道保存；商户品牌、协议、帮助和发布服务仍是租户级共用配置。
- 不因 APP 支持离线缓存而允许离线创建最终订单、确认支付或改变库存状态。
