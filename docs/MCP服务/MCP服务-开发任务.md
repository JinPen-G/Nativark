# MCP 服务：开发任务与接入设计

> 专项：Rental OS MCP 服务。
> 版本：v1.0；建立日期：2026-10-28。
> 正式依据：[需求](MCP服务-需求.md)；当前现场见[协作接续](MCP服务-协作接续.md)，实际已做见[开发记录](MCP服务-开发记录.md)。
> 与[Harness插件任务](../Harness插件/Harness插件-开发任务.md)共同安排首片，服务端能力只在本册实施，AGP只计客户端消费 / 增强。本轮是文档授权，不启动工程、安装、网络、迁移或发布。

## 1. 实施原则

1. MCP从第一片就是Harness的业务通路，不先实现插件专用API。原Web API保留；OAuth授权 / token / 撤销和原可信人类页面属于控制面，不是第二业务工具通路。
2. 复用原Auth / Guard / ALS、业务reader、Core、批准、持久任务 / 原键及审计，不新造通用Agent平台、业务权限库或第二执行器。MCP SDK专有类型留运输层，公共业务schema仍从`@rental-os/shared`正式出口消费。
3. 共用服务不共用token。不同client / 用户 / 空间独立grant；Harness直连与插件增强使用同一MCP接点和业务规则，授权持有与刷新只由一个客户端所有者处理。
4. 服务端做真实拒绝、投影和计量；提示词帮助理解和自主呈现，不承担安全执行。业务规则说明唯一维护，各客户端只加自身可用展示环境信息。
5. 所有旧客户端、原AI Native实现、文档、测试、WIP、依赖与隔离产物实际保留；固定成果核对后复用，不追活动HEAD、不以原测试绿色证明MCP接通。
6. 各完整片一次定向冒烟和必要类型检查；真实Host / OAuth / 数据库 / 模型及发布另列证据，不为文档整理启动服务或大回归。

## 2. 实施结构与固定交付

### 2.1 数据与调用路径

```text
Host的MCP客户端
  → HTTPS标准运输 / 请求校验
  → MCP资源身份与当前grant
  → 原Controller等价授权 / ALS / 当前字段与工具政策
  → 原目标计量 / 原操作定位
  → 现行业务reader / Core / 批准 / Task
  → 原收据 / 最少结果投影
  → MCP结果、必要说明
  → 原Host模型与呈现
```

实现前决定在原API进程内装配还是独立资源服务；两者都必须经过相同当前业务授权，不以方案选择绕Guard。同进程不意味着跳过原鉴权；分进程需正式受限委托 / 令牌交换，不透传MCP token或用管理员账号代理。禁止先建第二套REST业务接口再给MCP套壳。

### 2.3 固定公共交付

- **MCP-01：** 协议 / SDK与Host组合、资源 / 授权地址规则、原能力码到运输名、版本与风险 / 副作用、schema出口、首片字段和消费者约定。地址与字段不以占位示例当生产许可。
- **MCP-02：** 客户端登记、可信登录 / 同意 / 空间、grant / resource / scope、access与refresh、撤销、安全状态、后台CAS / 原保存收据；原身份解析和每次复验出口。
- **MCP-03：** 版本化发现、Tools / 可选Resources / Prompts、分页与通知、schema / 结果 / 错误、标准认证挑战；能力注册不调用未就绪生产者。
- **MCP-04：** 原持久目标准入与调用关联、原子次数 / 活跃 / 并发、分类限流、提交前原键、本人索引和精确收据；只读与副作用适用部分分片交付。
- **MCP-05：** 正式字段 / 用途 / 接收端释放政策、完整输出投影、来源与期限、业务 / 展示instructions和可选Prompts版本；提示词、工具schema和原业务发布保持同源。
- **MCP-06～09：** 当前实际业务出口、Core / 原选择 / 批准 / 任务消费及对应安全结果；不足保持unavailable。

MCP向AGP交付固定版本及真实拒绝 / 正常 / unknown证据；AGP反向提供Host兼容约束和消费证据，不另建同名服务端生产者。多个作者需独立工作树，公共Guard、shared、OpenAPI、迁移和后台文件各有唯一作者，不按两个专项名并行改同一文件。

## 5. 定向验收要求

### 5.1 身份、协议与治理

实际验证认证挑战、资源 / AS发现、PKCE / state / issuer / callback、码一次性、refresh并发 / 复用、取消迟到与撤销；按当前原Guard和ALS复核跨tenant / workspace / location / dataScope，不只测假身份适配。后台政策CAS及丢应答按原键恢复；应用 / 租户默认关闭且模型没有管理工具。

协议代次分别测试方法 / 元数据 / schema、分页、未知工具、旧缓存直接调用和标准错误。不声明未实现的Prompts / Resources / 通知；选择的SDK及HTTP重试可造成副作用重发时必须限制或拒绝相关能力，不能因SDK默认行为就免测。

### 5.2 事实、提示词与业务

使用实际原业务reader / Core和明确外部替身做定向行为，区分真实数据库锁 / 事务尚未验证。覆盖完整结构化及文本重复包装的64 KiB边界、2,000字符、50条、缺项 / 版本、无权限资源说明和注入内容。提示词及工具说明固定版本，Prompt调用本身不创建业务任务，不靠Host采用提示词才安全。

只读首片验证原目标累计，不以local Map或client自报人工豁免。报价保存、提案、批准消费、建单分别有原操作及首应答丢失恢复；web与不同MCP Host竞争只能产生原结果。计时 / 超时 / 取消 / 断线不被用作未执行证明，善后读取按独立当前读权限流。

### 5.3 真实客户端与发布

MCP-10记录Harness原生直连和需要插件补齐的差异；原生OAuth / 凭据 / scope / 重试不够时，只采用标准MCP客户端适配，不做私有业务代理。Codex、Claude Code按指定版本验证；Claude Desktop及其他Host只有验证后才宣传支持。记录instructions / Prompts是否采用、工具结果形态、错误 / 取消与恢复，不把UI截图当授权证据。

真实模型自主呈现另按当轮许可执行；离线录制 / 替身可验证固定输入输出和拒绝路径，但不代表真实模型或Host通过。生产部署、TLS / 反代、多实例撤销、签名和灰度另验，回退不删持久授权 / 原收据、不重发业务。
