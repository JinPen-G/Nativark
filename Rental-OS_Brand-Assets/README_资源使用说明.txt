Rental OS 品牌资源包 v1.0
日期：2026-09

本资源包使用你最终选定的版本：
- 蓝色渐变圆环 + 右上圆点
- Rental OS 深蓝字标
- 标语：Build a Rental World.
- 保持圆环主体的视觉居中，不移动右上圆点比例与位置关系。

目录说明

01_Logo
1. 01_logo-primary-with-tagline_官网宣传.png
   用途：官网 Hero、品牌介绍、宣传页、启动页等需要完整品牌信息的场景。

2. 02_logo-horizontal_后台与官网页头.png
   用途：管理后台顶部导航、官网 Header、登录页等横向空间有限的场景。

3. 03_logo-horizontal-white_深色背景.png
   用途：深色侧边栏、深色 Banner、深色页脚等。

4. 04_logo-mark-gradient_折叠菜单与品牌符号.png
   用途：后台侧栏折叠状态、品牌独立符号、头像位、加载页等。

5. 05_logo-mark-navy_单色与特殊场景.png
   用途：单色印刷、灰阶、特殊材质或不适合渐变的场景。

03_Guidelines
包含四张已确认的规范图：品牌标识、管理后台、官网、小程序/移动端。

品牌主色（以规范图为准）
- 品牌蓝：#1677FF
- 辅助蓝：#00C2FF
- 深色：#0F172A
- 中性灰：#64748B

使用注意
- 不拉伸、不压扁、不旋转 Logo。
- 不单独改变圆环与右上圆点的比例和相对位置。
- 浅色背景优先使用深色字标版本；深色背景使用白色字标版本。
- 小尺寸优先只使用 Logo Mark，不强行塞入完整文字。
- 字标属于 Logo 图形本身，实际项目中优先直接使用本资源包文件，不自行重新打字拼接。
